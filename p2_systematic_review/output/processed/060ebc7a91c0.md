## Abstract summary
The paper presents a conceptual framework and empirical experiments for quantum computing using the IBM Qiskit framework, detailing quantum gates, state representations, and implementations of algorithms such as Deutsch–Jozsa, Bernstein–Vazirani, Grover and Shor. It discusses practical aspects of running circuits on simulators and noisy cloud-backed quantum hardware, highlights current limitations due to noise and limited qubit counts, and argues Qiskit is a practical open-source environment for researchers and educators.
## Methodology
The paper presents a conceptual framework for quantum computation and demonstrates basic empirical experiments using the IBM Qiskit ecosystem. The authors implemented fundamental quantum gates (Pauli X/Y/Z, Hadamard, CNOT, phase/T/S) and several canonical quantum algorithms (Deutsch-Jozsa, Bernstein–Vazirani, Grover, and Shor variants) as example circuits. Implementation and execution were performed using the Qiskit SDK within a Python (Jupyter/Anaconda) environment and run on IBM Cloud resources (QASM simulator and IBM backends mentioned). For each algorithm the methodology followed the standard circuit-construction paradigm: define quantum registers and auxiliary qubits as needed, apply Hadamard layers to create superposition, implement the problem-specific oracle, apply algorithm-specific transforms (e.g., diffusion for Grover, inverse QFT for Shor), and measure the computational basis to obtain probability distributions. The paper reports measured/distributed probabilities and Bloch-sphere visualizations for small-scale (2–5 qubit) circuits and discusses the impact of noise (noting CX gates tend to be noisier than single-qubit gates). The work is essentially exploratory/demonstrative: it focuses on implementing and observing algorithmic behavior on Qiskit/IBM backends rather than applying these algorithms to a domain dataset such as finance.

**Algorithms used:** Deutsch-Jozsa, Bernstein-Vazirani, Grover's algorithm, Shor's algorithm
**Frameworks:** Qiskit, IBM Q Experience, QASM simulator, Qiskit Terra, Jupyter Notebook, Anaconda

**Experimental setup:** Implementations executed with Qiskit SDK in Python (Jupyter/Anaconda). Execution targets described include IBM Cloud / IBM Q Experience backends and the QASM simulator. The environment included quantum registers, quantum memory (qubits), QPU/backends and measurement to collect probability distributions. Noise sources in real devices are discussed qualitatively.
