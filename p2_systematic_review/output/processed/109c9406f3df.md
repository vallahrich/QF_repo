## Abstract summary
The paper proposes a hybrid quantum-classical graph neural network that uses parameterized quantum circuits as message-passing layers to model financial time series. The authors implement a proof-of-concept using PyTorch-Geometric and PennyLane, benchmark on the Cora citation dataset, and apply the model to NIFTY50 stock data to predict directional stock movements, finding performance comparable to classical models on modest qubit counts.
## Methodology
The authors propose a hybrid quantum-classical graph neural network (QGNN) in which parameterized quantum circuits (PQCs) are used as message-passing layers inside a GNN framework. The pipeline encodes classical node features into quantum states (using either angle encoding or amplitude encoding), applies a parameterized ansatz (either strongly entangling layers or simpler entangling layers), measures Pauli-Z expectation values to produce node messages, aggregates messages classically across each node's neighborhood and updates node features, and repeats this for multiple QGNN layers. The approach is evaluated both on the standard Cora citation graph (benchmark) and on financial time-series graphs derived from NIFTY50: correlation-based unweighted graphs where nodes represent stocks and node features are historical n-day price windows used to predict the direction of the next-day movement. For high-dimensional inputs (Cora), they reduce dimensionality using either a small classical input mapping layer (to enable angle encoding) or PCA (to 256 dimensions for amplitude encoding). Training is hybrid: cross-entropy loss is computed classically, and gradients are backpropagated through both the classical parameters and the quantum circuit parameters using Pennylane’s automatic differentiation and PyTorch integration. Optimization uses the Adam optimizer. Experiments compare different ansatzes, encoding schemes, and baseline classical models (GCNs of different sizes and XGBoost). All quantum circuits were simulated noiselessly on Pennylane’s Device Qubit simulator.

**Algorithms used:** Quantum Graph Neural Network (QGNN), Parameterized Quantum Circuits (PQC), Strongly entangling ansatz, Basic entangling ansatz, Graph Convolutional Network (GCN) - classical baseline, XGBoost - classical baseline, PCA (dimensionality reduction), Adam optimizer, Angle encoding, Amplitude encoding
**Frameworks:** Pennylane, PyTorch, PyTorch Geometric

**Experimental setup:** All quantum circuits were simulated on Pennylane's 'Device Qubit' noiseless simulator. Hybrid models were implemented with PyTorch and PyTorch Geometric for graph handling; Pennylane provided the quantum circuit simulation and automatic differentiation. Experiments included benchmarking on Cora (standard split) and evaluation on three correlation-derived NIFTY50 graphs (sparse, balanced, dense).

**Dataset:** Financial data: historical time-series for NIFTY50 (top 50 NSE stocks). Graphs were constructed from historical correlation: edges connect highly correlated stocks (unweighted). Three graph density variants were created (sparse, balanced, dense) with 49 nodes each and varying edge counts. Node features are n-day historical price windows and labels are the direction (up/down) on day n+1. Benchmark dataset: Cora citation network (2,708 nodes, 10,556 edges, 1,433 bag-of-words features per node, 7 labels).
## Experiment details
### Input
Cora: standard Cora citation dataset (2,708 nodes, 10,556 edges, 1,433 features). Preprocessing: for amplitude encoding PCA reduced features from 1,433 to 256; for angle encoding a classical input mapping layer was also used to reduce dimensionality to fit qubit count. Financial: NIFTY50 historical prices used to compute pairwise correlations; graphs formed by connecting highly correlated pairs to produce three variants (sparse, balanced, dense). Each financial graph contained 49 nodes (one stock likely excluded), each node had n features (n days of history) and one binary label (directional movement next day). Data were encoded into quantum circuits via angle or amplitude encodings. All simulations were run on Pennylane's noiseless device simulator.

### Process
1) Dataset preparation: Cora standard graph; NIFTY50: compute correlations, threshold to create three graph densities. 2) Feature preprocessing: for Cora either PCA(1433->256) for amplitude encoding or classical mapping to lower dim for angle encoding; financial features small enough to avoid dimensionality reduction. 3) Model construction: build hybrid QGNN with quantum message-passing layers (PQC per node) and classical aggregation/update. 4) Quantum encoding: map node features into quantum states via angle or amplitude encoding. 5) Quantum ansatz: apply either strongly entangling or simple entangling layers (repeated). 6) Measurement: compute Pauli-Z expectation(s) per node to form node messages. 7) Aggregation: classical neighborhood aggregation and node update (with optional learnable classical weights). 8) Stack multiple QGNN layers (three layers in experiments). 9) Loss & optimization: compute cross-entropy loss and optimize both quantum and classical parameters using Adam with gradients computed via Pennylane-PyTorch autodiff. 10) Evaluation: compare test accuracy, cross-entropy loss (Cora) and cross-entropy, F1, ROC-AUC (financial) against baselines (GCN variants and XGBoost). Key hyperparameters used in reported experiments: 3 QGNN layers, 10 repetitions of the circuit ansatz per layer, total ~90 learnable quantum parameters on 7 qubits for the Cora experiments. Training was done in batches; exact epoch count, learning rate, and batch size are not specified in the paper.

### Output
Results reported as cross-entropy loss and test accuracy for the Cora benchmark; for the NIFTY50 experiments they report cross-entropy loss, F1 score, and ROC AUC across the three graph density variants (sparse, balanced, dense). Baselines included random baseline, classical GCNs (h=5 and h=6 variants), and XGBoost. They provide numerical comparisons (tables) showing that their hybrid QGNN performs comparably to similarly-sized classical GNNs on Cora and can outperform classical baselines on some financial graph variants in terms of F1 score.

## Quantum advantage claim
**Classification:** not-applicable

The paper does not demonstrate a clear, general quantum advantage. QGNNs achieved comparable or slightly better F1 scores in some small-scale, simulated experiments (NIFTY50 sparse/balanced graphs) but were outperformed by larger classical GNNs on Cora; experiments were performed on a noiseless simulator and scaling/optimization issues (barren plateaus) were reported, so no conclusive quantum computational advantage is shown.
## Limitations
- NISQ-era hardware constraints: short coherence times, high noise levels, and low numbers of logical qubits (author-stated).
- Scalability: optimizing circuits becomes increasingly difficult as the number of qubits increases; classical larger GNNs outperform the QGNN when scaled up (author-stated).
- Barren plateaus: certain ansatz and larger circuits lead to vanishing gradients which hinder training (author-stated).
- Use of a noiseless simulator (Pennylane 'Device Qubit') rather than real quantum hardware, so results may not reflect performance under realistic noise (author-stated).
- Dimensionality constraints on input features require preprocessing (PCA) or an extra classical layer to reduce dimensions before quantum encoding (author-stated).
- Problem scope is limited: the financial experiment addresses a milder task—predicting direction of stock movement—rather than full portfolio optimization or pricing (author-stated).
- [inferred] Small-scale financial dataset and graph construction: experiments used NIFTY50-derived graphs (49 nodes) built from simple correlation thresholds and unweighted edges, which may not capture full market complexity.
- [inferred] Potential information loss from dimensionality reduction (PCA) or classical input mapping prior to quantum encoding.
- [inferred] Ansatze and encoding choices (angle vs amplitude) introduce trade-offs (gate depth, qubit count, padding) that may limit applicability to higher-dimensional financial data.
- [inferred] Evaluations focus on ML metrics (loss, accuracy, F1, ROC-AUC) without economic/financial performance measures (e.g., returns, Sharpe ratio, transaction costs).
- [inferred] Limited assessment of robustness/generalization across different market regimes, time periods, or out-of-sample stress scenarios.
- [inferred] Resource and runtime costs (classical-quantum hybrid overhead, simulation time) are not reported, so practical deployment feasibility is unclear.
## Open questions

- Can QGNNs demonstrably achieve a quantum advantage over classical GNNs for realistic financial tasks (beyond parity or toy datasets)?

- Can the proposed hybrid QGNN be extended from direction prediction to end-to-end portfolio optimization (incorporating constraints, transaction costs, and risk measures)?
- How robust are QGNN models across different market regimes (bull, bear, high volatility) and different asset universes beyond NIFTY50?
