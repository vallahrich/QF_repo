## Abstract summary
This conference paper evaluates a hybrid quantum-classical neural network (QCNN) using a continuous-variable variational quantum circuit for binary credit default prediction and compares it to a classical neural network. Using a 17k-record credit card dataset with preprocessing (including under-sampling and LDA feature reduction), the QCNN achieved higher predictive accuracy (up to 97.63% vs. 91.20% for the classical model) but required substantially longer training time per epoch. The work demonstrates a proof-of-concept quantum advantage in classification accuracy for a financial task while noting increased computational cost.
## Methodology
The study compares a classical neural network baseline to a hybrid quantum-classical convolutional neural network (QCNN) on a binary credit default prediction task. The authors used a publicly available synthetic credit card default dataset (≈17k records, 20 predictors + binary target). Preprocessing included removing nulls and an ID column, correcting class imbalance by undersampling normal cases to achieve a 3:1 normal:default ratio, standardizing features with scikit-learn's StandardScaler, and reducing dimensionality from 20 to 10 features using Linear Discriminant Analysis (LDA) (≈97.67% retained variability). The classical baseline was implemented in TensorFlow/Keras as a Sequential Dense model with one hidden layer (10 nodes), ReLU activation on the input, sigmoid on the output, binary cross-entropy loss, Adam optimizer, and an exponentially decaying learning rate schedule. The hybrid QCNN pipeline first passes the same 10 LDA features through a classical fully connected network (two hidden layers, ELU activations) to produce inputs for the quantum layers. Quantum encoding used amplitude embedding (Pennylane). The variational continuous-variable (CV) quantum circuit (implemented via the Strawberry Fields TensorFlow device through Pennylane) comprises blocks with an interferometer, squeezer, interferometer, displacement, and Kerr gates (interferometers built from rotations and beamsplitters). This quantum block was repeated five times. The quantum layer(s) were converted into Keras-compatible layers with tunable parameters, measured, and optimized with the classical Adam optimizer. Models were trained with 10% of data held out for testing; the classical model was trained for 30 epochs and the QCNN for 40 epochs (30+10 extra). Training/validation accuracy and loss per epoch were recorded. The QCNN achieved substantially higher accuracy (≈96%+ validation) but required significantly longer per-step runtime (~70s vs ~7s for the classical model).

**Algorithms used:** Variational Quantum Algorithm (VQA) / Variational Quantum Circuit (continuous-variable), Amplitude embedding (quantum data encoding), Linear Discriminant Analysis (LDA), Classical Neural Network (Keras Sequential Dense), Adam optimizer, Exponential learning-rate decay
**Frameworks:** TensorFlow / Keras, Pennylane, Strawberry Fields (Strawberry Fields TensorFlow device via Pennylane), scikit-learn (StandardScaler, LDA), NumPy, Pandas

## Experiment details
### Input
Source: Pratikto (2023) synthetic credit card default dataset (DOI: 10.17632/jrss9jdjz9.1). Size: ~17,000 cases. Features: 20 predictors (demographics, credit/payment history, credit amount, number of cards, etc.) + binary target. Preprocessing: drop nulls and client ID; address class imbalance via undersampling normal cases to a 3:1 normal:default ratio; StandardScaler normalization (zero mean, unit variance); reduce features 20->10 via LDA (retaining ≈97.67% variability); one-hot encode outputs; split with 10% held out for testing.

### Process
1) Load dataset, clean nulls/ID, undersample majority class to 3:1 ratio, standardize features. 2) Apply LDA to reduce features to 10. 3) Baseline classical pipeline: train TensorFlow/Keras Sequential Dense model (one hidden layer of 10 nodes, ReLU and sigmoid activations), binary cross-entropy loss, Adam optimizer, exponential learning-rate decay, train for 30 epochs, record training/validation accuracy and loss. 4) Hybrid QCNN pipeline: feed 10 LDA features into a classical fully connected subnetwork (two hidden layers, ELU activations); amplitude-embed the classical outputs into a continuous-variable variational quantum circuit (Pennylane/Strawberry Fields). The variational block architecture: interferometer -> squeezer -> interferometer -> displacement -> Kerr gates; interferometers implemented with rotations and beamsplitters. Repeat this quantum block 5 times. Convert the parameterized quantum circuit into a Keras-compatible layer (weights initialized and tunable). Measure outputs from quantum circuit and optimize parameters with classical Adam optimizer. Train QCNN for 40 epochs (30 + additional 10), using 10% test split, and log accuracy/loss per epoch. 5) Compare metrics and per-epoch runtimes between models.

### Output
Primary outputs: per-epoch training and validation accuracy and loss. Reported numeric results: classical model at 30 epochs — training accuracy 91.22%, training loss 0.2627; validation accuracy 91.11%, validation loss 0.3128. QCNN at 30 epochs — training accuracy 96.34%, training loss 0.0354; validation accuracy 95.18%, validation loss 0.0487. QCNN at 40 epochs — training accuracy 97.63%, training loss 0.0321; validation accuracy 96.21%, validation loss 0.0451. Additional reported metric: per-step/epoch runtime ~70 seconds for QCNN vs ~7 seconds for classical baseline. No other baselines (e.g., logistic regression, XGBoost) reported.

**Results summary:** The authors implemented and compared a classical neural network and a hybrid quantum-classical neural network (QCNN) for a binary credit-default prediction task on a ~17k-record dataset. After preprocessing (undersampling to 3:1, standardization, and LDA to 10 features), the classical model (single hidden layer, 10 nodes) reached ~91.2% accuracy (training/validation ~91.2%/~91.1%) after 30 epochs. The hybrid model used a classical preprocessing sub-network then amplitude-embedded inputs into a continuous-variable variational circuit (interferometer, squeezer, interferometer, displacement, Kerr gates, repeated in five blocks) implemented with Pennylane/Strawberry Fields; it reached higher accuracy (training 97.63%, validation 96.21% after 40 epochs) and much lower loss values. However, the QCNN training per-step time was substantially larger (~70s vs ~7s), and training exhibited higher variability. The authors conclude that hybridization produced an accuracy advantage in this experimental setup but at higher computational cost and note that further work is needed (ansatz/feature-map/hyperparameter tuning and larger architectures).

## Quantum advantage claim
**Classification:** demonstrated

The paper reports an empirical accuracy advantage for the hybrid QCNN over the tested classical neural network on the used credit-default dataset (higher training and validation accuracies and lower loss). The advantage is demonstrated within the authors' simulated/implemented experiment but is limited: it came with substantially higher training time per step and higher training variability, was shown on a single dataset and architecture, and was performed using CV simulation (Pennylane/Strawberry Fields), so generalization to other datasets, models, or real quantum hardware remains unproven.
## Limitations
- QCNN required substantially more training time per epoch (avg ~70s) compared to the classical network (~7s), increasing overall runtime and compute cost.
- QCNN exhibited higher variability in accuracy and loss during training compared to the classical model.
- NISQ-era constraints (noise, decoherence) and lack of scalable qRAM are noted as practical limitations for near-term quantum approaches (general literature limitation noted by authors).
- [inferred] The experiment was performed using the PennyLane / Strawberry Fields TensorFlow device (simulation); results were not validated on physical quantum hardware.
- [inferred] The study compared the QCNN to a relatively simple classical baseline (one hidden layer with 10 nodes) rather than against stronger classical models or state-of-the-art classical classifiers.
- [inferred] Dataset handling choices (undersampling normal cases to a 3:1 ratio) may introduce bias or affect generalizability of the reported performance.
- [inferred] The evaluation used a single train/validation split (90/10) and a limited number of runs; no cross-validation or statistical significance testing was reported.
- [inferred] The model used feature reduction to 10 features via LDA and a modest-size variational circuit (five repeated blocks); scalability to higher-dimensional inputs and larger circuits was not demonstrated.
- [inferred] Only one encoding (amplitude embedding) and one variational ansatz/circuit structure were evaluated; sensitivity to alternative encodings or ansatz choices remains untested.
- [inferred] Potential overfitting risk was not fully quantified despite high reported accuracies (no reported metrics such as AUC, precision/recall per class imbalance, or external validation).
## Open questions
- Does the observed accuracy advantage of the QCNN generalize to execution on real quantum hardware under realistic noise conditions?
- Can QCNN architectures be optimized (ansatz, encoding, circuit depth) to reduce training time and match or beat classical models in runtime as well as accuracy?
- How sensitive are results to the choice of data encoding / feature map and to different variational ansatz designs?
- Would the QCNN maintain its advantage against stronger classical baselines (deeper networks, ensemble methods, gradient-boosted trees) or after more extensive classical hyperparameter tuning?
- How does the hybrid approach scale to larger, higher-dimensional, or more complex financial datasets and multi-class problems?
- What is the impact of different strategies for handling class imbalance (e.g., oversampling, SMOTE, cost-sensitive learning) on QCNN vs classical performance?
- Are the reported accuracy improvements statistically significant and robust across multiple random seeds, folds, and dataset partitions?
- What are the practical cost-benefit trade-offs (compute time, resource requirements) of deploying hybrid QCNNs in production financial systems?
- How would the absence of efficient qRAM affect performance and feasibility for large-scale classical data encoding in quantum circuits?

**Future work:**
- Evaluate alternative and more advanced feature maps and variational ansatz designs for the quantum circuits.
- Conduct more comprehensive hyperparameter optimization, with emphasis on learning rate and batch size tuning.
- Explore larger and more intricate hybrid quantum-classical neural network architectures for more demanding classification problems.
- Test and benchmark QCNN performance on contemporary physical quantum hardware (accounting for NISQ noise) rather than only in simulation.

## Contradictions
- The paper claims a quantum advantage in classification accuracy but evaluates only on a simulated continuous-variable circuit and compares against a single modest classical baseline (one-hidden-layer NN). Lack of stronger classical baselines (e.g., XGBoost, ensemble methods) and real-hardware validation undermines the strength of the superiority claim (contradiction: classical-vs-quantum).
- Although higher accuracy is reported, the QCNN incurs ~10x slower per-epoch runtime and no discussion of resource scaling (modes/qumodes, circuit depth, shots) is provided, which contradicts practical scalability expectations and calls into question near-term feasibility for larger, real-world datasets (contradiction: scalability).
