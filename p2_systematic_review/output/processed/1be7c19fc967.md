## Abstract summary
The paper proposes a hybrid framework that combines quantum computing and generative AI to deliver real-time credit fraud detection by fusing quantum-enhanced learning models with adversarially trained generative systems that synthesize realistic fraud scenarios. Experimental results on benchmark and synthetic datasets report higher accuracy, lower latency (sub-30ms), reduced false positives/negatives, and improved adversarial robustness versus traditional ML baselines, with attention to privacy-preserving federated learning and compliance considerations.
## Methodology
The study follows a design-science approach combining theoretical modelling with component-level simulation to build and evaluate a hybrid Quantum Computing (QC) + Generative AI (GenAI) credit-fraud detection system. The methodology is organized around three objectives: (1) real-time anomaly detection on high-dimensional transactional patterns, (2) synthetic fraud generation to improve training coverage, and (3) adversarial risk mitigation through model hardening. Architecturally the system is layered: an input/preprocessing layer ingests real-time transaction streams and applies quantum-friendly feature mappings (angle- and amplitude-encoding); a dual-engine core comprising a Quantum Detection Engine (QSVMs and quantum neural networks) and a Generative Engine (GANs and transformer-based models) for synthetic fraud simulation and adversarial training; and an adversarial risk mitigation layer that applies differential privacy, gradient masking/regularization and federated learning patterns. Implementation relied on quantum simulation/tooling (IBM Qiskit, PennyLane) and classical deep-learning frameworks (TensorFlow, PyTorch), with real-time integration via message queues/APIs (Kafka, REST). Evaluation compared the hybrid pipeline to classical and GenAI-only baselines using detection accuracy, false positive/negative rates, inference latency, and an adversarial robustness score. The approach uses iterative adversarial training where GenAI-generated fraud samples augment training data to harden the quantum-enhanced detectors, with a real-time feedback loop for model updates based on analyst decisions.

**Algorithms used:** Quantum Support Vector Machine (QSVM), Quantum Neural Networks (QNN), Quantum Boltzmann Machine (mentioned), Quantum-enhanced GANs (QGANs) (mentioned), Generative Adversarial Networks (GANs), Transformer-based generative models, Random Forest (baseline), Adversarial training (gradient masking), Differential privacy, Federated learning (training paradigm)
**Frameworks:** Qiskit, PennyLane, TensorFlow, PyTorch, Kafka, REST APIs

**Experimental setup:** Quantum circuit modeling and simulation were performed using IBM Qiskit and PennyLane (quantum simulators). Generative models and discriminators were implemented in TensorFlow/PyTorch. Real-time ingestion and feedback used message queues (Kafka) and REST APIs. The authors also refer generically to quantum-as-a-service/cloud-based quantum simulators but do not specify a particular QPU or cloud provider.

**Dataset:** Historical credit card transaction data (public + synthetic), enriched with GenAI-generated fraudulent cases. Exact dataset name(s) and size are not specified in the paper.
