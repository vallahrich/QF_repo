## Abstract summary
The paper introduces QuLTSF, a hybrid quantum-classical model that combines classical linear layers with a variational quantum circuit (VQC) to perform multivariate long-term time series forecasting (LTSF). Evaluated on a standard Weather dataset, QuLTSF outperforms state-of-the-art classical linear baselines (Linear, NLinear, DLinear) in MSE and MAE, demonstrating the potential of quantum machine learning for LTSF.
## Methodology
The authors propose QuLTSF, a hybrid quantum-classical model for multivariate long-term time series forecasting. For each univariate channel (channel-independence), an input classical linear layer with trainable weights (Win) and bias maps an L-length input sequence to a 2N-length real vector. This 2N vector is encoded into an N-qubit quantum state using amplitude embedding. A variational quantum circuit (VQC) with a hardware-efficient ansatz (K layers, each layer containing 3-parameter single-qubit rotations on each qubit plus a fixed circular CNOT entangling pattern) is applied to the encoded state. The expectation value of the Pauli-Z operator on each qubit produces an N-length quantum hidden representation which is passed to an output classical linear layer (Wout, bout) to predict the T-length future sequence. The hybrid model (input linear layer, VQC parameters, output linear layer) is trained end-to-end by minimizing mean squared error (MSE) using the Adam optimizer. Evaluation uses MSE and MAE and compares QuLTSF to several baselines (Linear, NLinear, DLinear, FEDformer, Autoformer, Informer). Experiments use the Weather dataset (21 features) with a 70/10/20 train/val/test split, and ablations include multiple forecast horizons (T ∈ {96,192,336,720}) and varying input lengths L. Key training hyperparameters (reported) include N=10 qubits, K=3 VQC layers, batch size 16, and learning rate 1e-4.

**Algorithms used:** Variational Quantum Circuit (VQC), Amplitude embedding (quantum data encoding), Hardware-efficient ansatz (parameterized single-qubit rotations + circular CNOT entangling), Pauli-Z expectation-value measurement, Classical linear layers (input and output), Adam optimizer
**Frameworks:** PennyLane

**Experimental setup:** Experiments were implemented by the authors and executed on SMU's Crimson GPU cluster (classical GPU-based simulation). The hybrid quantum-classical model was trained via classical optimizers; no physical quantum processing unit (QPU) was reported. Code is available on the authors' GitHub repository.

Preprocessing: authors map the input L-length sequence per channel through a trainable linear input layer to produce a 2N-length vector which is amplitude-embedded into the quantum circuit; no additional preprocessing (e.g., normalization technique) is described in detail in the paper.

## Limitations
- Implementation on quantum hardware poses significant challenges (noise, decoherence, error correction requirements) that degrade performance and make on-hardware deployment difficult.
- The barren plateau phenomenon can cause vanishing gradients and complicate optimization of variational quantum circuits (VQCs).
- QuLTSF uses a generic hardware-efficient ansatz; the chosen ansatz may be suboptimal for the dataset/problem.
- [inferred] Experiments are conducted on a single dataset (Weather); generalization to other datasets and domains (notably financial time series) is not demonstrated.
- [inferred] The work appears to be evaluated in simulation / on classical hardware (GPU cluster) rather than on real quantum devices, so practical on-device performance and noise effects are not tested.
- [inferred] The model assumes channel-independence (each univariate series treated separately), which may limit the ability to capture cross-series (multivariate) dependencies.
- [inferred] Scalability is unclear: experiments use a small number of qubits (N=10) and shallow depth (K=3); performance and trainability at larger qubit counts/circuit depths are not evaluated.
- [inferred] Benchmarking is limited: while compared to linear baselines and some transformers, broader comparisons (and comprehensive evaluation against preprocessing-enhanced modern transformers across datasets) are limited.
- [inferred] Sensitivity to design choices and hyperparameters (data embedding method, ansatz architecture, number of qubits/layers, measurement choices) is not thoroughly explored.

- What are the most effective classical-to-quantum encoding/embedding strategies for time series input (amplitude, angle, other encodings)?
- How do QML LTSF models scale in practice with increasing qubit counts and circuit depth in terms of accuracy, training cost, and robustness to noise?
- Can problem-specific circuit designs and alternative optimization strategies (beyond generic hardware-efficient ansätze) yield consistent, practical advantages over classical models?
- How do QML models compare to state-of-the-art classical models (including preprocessing-enhanced transformers) across a diverse set of forecasting tasks and metrics?
