## Abstract summary
The paper formulates a small-scale binary portfolio selection problem as a QUBO mapped to an Ising Hamiltonian and implements QAOA on a simulator, comparing its outputs to a classical QUBO solver. Emphasizing a pedagogical exposition of QAOA, the study finds that QAOA can recover near-optimal solutions for a 6-asset instance but does not claim practical quantum advantage.
## Methodology
The author formulates a discrete portfolio selection problem as a QUBO of n=6 assets, where each binary variable xi ∈ {0,1} indicates asset inclusion. Expected returns µ and covariance matrix Σ are synthetically generated; the QUBO objective is Cost(x) = -∑_i µ_i x_i + λ ∑_{i,j} Σ_{ij} x_i x_j plus penalty terms (cardinality/budget) to enforce constraints. The QUBO is mapped to an Ising cost Hamiltonian HC = ∑_i h_i Z_i + ∑_{i<j} J_{ij} Z_i Z_j using xi = (1 - Z_i)/2. QAOA is implemented with the standard mixer HM = ∑_i X_i, starting from |+>^{⊗6}, and alternating p layers UC(γ)=e^{-iγHC} and UM(β)=e^{-iβHM}. Circuits for p=1 and p=2 (2p variational parameters) are optimized in a hybrid loop: a classical optimizer (COBYLA) proposes (γ,β), the parameterized circuit is executed on a Qiskit Aer simulator (statevector) using 1024 shots to obtain measurement distributions, the expectation ⟨HC⟩ (and sampled bitstrings) are evaluated, and the optimizer updates parameters to minimize energy. A classical exact QUBO solver is used as a baseline. Recorded outputs include measured bitstrings, expected return, variance, and QUBO cost; results are compared across QAOA depths and the classical solution. The implementation and scripts are reported to be available in a public GitHub repository.

**Algorithms used:** QAOA, Classical exact QUBO solver

**Dataset:** Synthetic financial data: generated expected returns (µ_i) and covariance matrix (Σ_{ij}) for a small controlled instance of n=6 assets. ## Contradictions
- The paper's empirical results show QAOA did not outperform the exact classical QUBO solver on the tested instance (classical cost -17.745 vs best QAOA -17.740), which runs counter to any broad claims that QAOA already yields superior solutions on small practical portfolio problems.
- Observed non-monotonic behavior with depth (p=2 worse than p=1) contradicts a common expectation that simply increasing QAOA depth will reliably approach or surpass classical performance; this highlights scalability and optimizer-landscape challenges even for small n.
