## Abstract summary
The paper combines a classical dot-matrix sequence alignment approach with a Grover-like quantum multi-pattern recognition algorithm to accelerate pairwise sequence alignment by encoding diagonal segments as quantum search indices. It does not compute optimal alignments but quickly locates similar regions (particularly effective when one sequence is much shorter), and claims perfect recognition when the trained pattern set exceeds one-third of all patterns, proposing a hybrid quantum-classical workflow for large-scale alignments.
## Methodology
The paper proposes a hybrid sequence-alignment methodology that maps dot-matrix diagonals (recurrence plot diagonals) to one-dimensional vector datasets and then applies a quantum multi-pattern recognition algorithm (based on Zhou & Ding 2008) that is structurally similar to Grover's search. A learning pattern set is prepared consisting of patterns P and spurious patterns S, each represented as i-bit binary basis states, with the constraint s = n and s + n < 2^i. The initial quantum state |φ0> is encoded as an equal superposition over the training patterns: |φ0> = (1/√(2n)) Σ|x1...xi> for xi in P∪S. Two unitary operators are iteratively applied: U2n = I − (1 − i) Σ|xi><xi| (phase rotation on 2n indices) and Uφ = (1 + i)|φ0><φ0| − i I (inversion about the average with a complex factor). The iteration count is T ≈ (π/4)·√(N/n) where N = 2^i. In practice, to reduce encoding complexity for long target sequences, the long sequence is divided into shorter fragments (example: fragments of length 50), each fragment producing a set of diagonal datasets that are searched separately; classical post-processing assembles matches across fragments. The method treats each full diagonal as a search index and pads shorter diagonals to the pattern length. The authors note that when the learned pattern set exceeds one third of the total patterns the multi-pattern recognition succeeds with probability 100%. The approach is intended to quickly locate similar regions (diagonals) before applying classical local alignment methods.

**Algorithms used:** Quantum multi-pattern recognition (Zhou & Ding 2008), Grover-like quantum search / amplitude amplification

## Contradictions
- The paper states or implies that pairwise sequence-alignment computation is 'NP' (and uses 'NP complete' in keywords), which contradicts standard results: pairwise dynamic-programming algorithms (Needleman–Wunsch / Smith–Waterman) are polynomial-time. This mischaracterisation undermines the motivation for claiming an exponential/NP advantage.
- The authors claim a practical speed advantage using Grover-like iterations but provide no resource accounting (qubit counts, oracle/gate costs, state-preparation complexity). This contradicts the implicit scalability claim: without concrete encoding and oracle cost analysis, the theoretical √(N/n) iteration count may not translate into end-to-end speedup for realistic problem sizes.
