## Abstract summary
This paper implements portfolio optimization by formulating a mean-variance problem as a QUBO and solving it with quantum algorithms (QAOA/VQE) using NVIDIA's CUDA Quantum/cuQuantum GPU-accelerated simulators. Empirical results on up to 30 assets show that GPU simulation significantly outperforms CPU (notably beyond ~15 assets) and exhibits consistent performance up to about 27 qubits/assets before computational time increases sharply, highlighting the benefits and scalability limits of GPU-accelerated quantum simulation for financial optimization.
## Methodology
The study formulates the mean-variance portfolio optimization problem as a QUBO and maps it to an Ising Hamiltonian to be solved with quantum variational algorithms. Adjusted closing prices for a set of 30 tickers were downloaded from Yahoo Finance for the period 2020-12-25 to 2022-12-25. Log returns were computed and the mean return vector (μ) and covariance matrix (Σ) were derived. A binary variable xi represents inclusion/exclusion of asset i, producing a QUBO objective H(x)=x^T Q x - λ ∑ μ_i x_i which is converted to an Ising form via σ_i = 2 x_i - 1. The cost Hamiltonian HC encodes the covariance (risk) and expected-return term; the mixer Hamiltonian HM is a sum of Pauli-X operators. They implement a QAOA ansatz (alternating cost and mixer unitaries with parameters {γ_k, β_k} for p layers) and use the QAOA circuit as the variational ansatz within a VQE-style hybrid loop: evaluate expectation ⟨H⟩ on a quantum state, then update parameters with a classical optimizer. The classical optimizer used is COBYLA. Simulations were run using NVIDIA’s CUDA Quantum / cuQuantum (GPU-accelerated statevector simulation) and compared against a CPU implementation (64 threads). Experiments varied the number of assets/qubits up to 30 and measured execution time (runtime) and scalability, with particular attention to GPU vs CPU performance and scaling behavior (noting a CPU runtime blow-up after ~15 assets and a GPU runtime inflection around 27 assets).

**Algorithms used:** QAOA, VQE, QUBO formulation, Ising model mapping, COBYLA (classical optimizer)
**Frameworks:** CUDA Quantum, cuQuantum SDK, Yahoo Finance API (data acquisition)

**Experimental setup:** GPU-accelerated statevector simulations using NVIDIA cuQuantum (CUDA Quantum). Hardware: NVIDIA A100 80GB Tensor Core GPU; dual AMD Rome 7742 CPUs (128 cores); system memory 2 TB. CPU comparisons used 64 threads. COBYLA used as the classical optimizer. Simulations ran up to 30 qubits/assets.

**Dataset:** Adjusted closing prices for 30 equity tickers (diverse industries) from Yahoo Finance for the period 2020-12-25 to 2022-12-25. Log returns were computed and used to derive per-asset mean returns (μ) and the covariance matrix (Σ).

## Contradictions
- The reported 'quantum advantage' is limited to faster GPU-accelerated classical simulation (cuQuantum on an A100) versus a CPU statevector baseline; this does not demonstrate algorithmic or hardware quantum speedup on real QPUs.
- Although the paper highlights improved simulator scalability on GPU, it also reports a sharp runtime inflection around 27 qubits and CPU blow-up after ~15 qubits, contradicting any claim that the variational QAOA/VQE approach scales smoothly to substantially larger, practical portfolio sizes.
