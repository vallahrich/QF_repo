## Abstract summary
This preprint proposes a Particle Swarm Optimization (PSO)-tuned Quantum Neural Network (QNN) using variational quantum circuits for anomaly detection in securities transactions. PSO is applied both for feature selection and for optimizing QNN weights and biases; evaluation on the IEEE-CIS Fraud Detection dataset reports 98.55% precision and an MCC of 0.94, outperforming LSTM, KNN, and SVM baselines.
## Methodology
The study proposes a PSO-optimized Quantum Neural Network (QNN) pipeline for anomaly (fraud) detection on securities transaction data. The methodology comprises three main stages: (1) data preprocessing using Min-Max normalization, missing-value handling, categorical encoding and a 70/30 train-test split (with unspecified sampling procedures to mitigate class imbalance), (2) wrapper-style feature selection using a binary Particle Swarm Optimization (PSO) where each particle is a binary vector indicating inclusion/exclusion of features; velocity updates follow standard PSO and are mapped to binary choices via a sigmoid transfer function with threshold (θ, commonly 0.5), and particle fitness is evaluated by classification accuracy of the QNN on validation data, and (3) QNN model training where a variational quantum circuit-based QNN (inputs encoded into qubits, parameterized rotation and entangling gates, quantum perceptron formulation provided) is used for binary classification. PSO is reused to optimize the QNN weights and biases: each particle encodes the full set of QNN parameters (dimension h = a*b + 2a + 1, where a is hidden neurons and b is number of selected features). Standard PSO update formulas with inertia weight w, cognitive/social coefficients c1 and c2, and random factors r1,r2 are applied; positions (weights) are updated and the fitness is assessed by classification performance (accuracy and related metrics). The optimized global-best particle is decoded to initialize/finalize the QNN parameters and used for final test predictions. Results are compared against classical baselines (LSTM, KNN, SVM) using metrics including accuracy, precision, recall/sensitivity, specificity, FPR, FNR, F1-score, MCC and NPV.

**Algorithms used:** Variational Quantum Circuit / Quantum Neural Network (QNN), Particle Swarm Optimization (PSO) - binary variant for feature selection and continuous variant for weight optimization, Min-Max normalization (preprocessing), Baselines: Long Short-Term Memory (LSTM), k-Nearest Neighbors (KNN), Support Vector Machine (SVM)

**Dataset:** IEEE-CIS Fraud Detection dataset: ~590,540 transactions, 434 (obfuscated) features including transaction metadata and identity/device variables, class imbalance with ~3.5% fraudulent transactions.
