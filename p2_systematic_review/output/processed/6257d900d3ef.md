## Abstract summary
This paper presents a hybrid quantum-classical approach to cross-border financial fraud detection, directly comparing classical SVMs with Quantum SVMs (QSVMs). It uses angle encoding and quantum feature maps to build quantum kernels (with PCA for dimensionality reduction to fit current hardware limits), and reports that QSVMs can be competitive and complementary to classical models, supporting hybrid deployment for improved detection of complex fraud patterns.
## Methodology
The study implements a hybrid, end-to-end comparative methodology to evaluate classical Support Vector Machines (SVM) against Quantum SVM (QSVM) for cross-border financial fraud detection. A tabular transaction dataset (Transaction ID, Amount, Country Risk, Time of Day, Sender Blacklisted, Sender Age Days, Label) is validated and preprocessed: categorical Time-of-Day is encoded to binary, optional cohort filtering is supported, features are standardized (zero mean, unit variance) and dimensionality is reduced with PCA to a maximum of four components to make subsequent quantum processing feasible. The classical baseline uses scikit-learn's SVC with an RBF kernel. The quantum pipeline is hybrid: classical data (after scaling and PCA) are normalized to [0, π] and encoded into quantum states using angle encoding (Ry rotations) on qubits, followed by entangling gates (CNOT) to capture feature interactions. A quantum kernel matrix is computed by measuring state overlaps (expectation values of Pauli-Z operators) between pairs of encoded states; this precomputed quantum kernel is used with an SVM classifier. Circuits are implemented and simulated with PennyLane (default qubit simulator). Models are evaluated and compared using industry-relevant metrics (accuracy, precision, recall, F1-score, false-positive rate), ROC/AUC, and confusion matrices. The study also inspects feature selection differences (including use of Z/ZZ feature maps) and discusses hybrid deployment where classical models handle routine transactions and the QSVM is applied to challenging cases.

**Frameworks:** PennyLane, scikit-learn

**Experimental setup:** Hybrid quantum-classical setup using PennyLane's default qubit simulator for quantum circuit simulation; classical baselines implemented with scikit-learn. Quantum kernel computed via state overlaps (expectation values of Pauli-Z). Evaluation via standard classification metrics and visualizations (ROC/AUC, confusion matrix).

**Dataset:** A proprietary/unspecified cross-border financial transaction dataset with fields: Transaction ID, Amount, Country Risk (numerical), Time of Day (Day/Night), Sender Blacklisted (0/1), Sender Age Days, Label (0 = Genuine, 1 = Fraud).
