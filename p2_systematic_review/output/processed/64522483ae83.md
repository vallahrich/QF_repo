## Abstract summary
This editorial introduces a special issue collecting extended papers from the Quantum Software Architecture Workshop at ICSA 2021, emphasizing the need for systematic approaches to architecting hybrid quantum-classical software and addressing challenges such as integration, state preparation, scalability, testing, deployment, and reuse. It summarizes four contributions on data encoding patterns for quantum algorithms, analysis of a hybrid quantum-classical neural network, QuaSiMo (a composable library for hybrid quantum simulation workflows), and QProv (a provenance system for quantum computing).
