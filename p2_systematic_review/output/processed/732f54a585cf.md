## Abstract summary
This paper proposes a multi-stage ransomware detection framework combining correlation-coefficient based min-max normalization for preprocessing, a hybrid Osprey Optimization with an enhanced Sparrow Search Algorithm for feature selection, and a hybrid quantum-classical convolutional neural network optimized by Boosted Sooty Tern Optimization. Evaluated on CICIDS2017 and mixed ransomware traffic, the method reports very high performance (claimed accuracy ~99.7%, F1 ~99.5%) with low error rate and short computational time, arguing suitability for real-time deployment.
## Methodology
The study proposes a multi-stage ransomware-detection pipeline that combines classical preprocessing, metaheuristic feature selection, and a hybrid quantum-classical convolutional neural network optimized by a bio-inspired optimizer. Input traffic labeled from CICIDS2017 and ransomware captures is first preprocessed using a Correlation Coefficient-based Min–Max Normalization (CCMMN) step: features are min–max scaled to [0,1], Pearson correlation coefficients to the label are computed, and features are weighted according to those correlations. Feature selection is then performed by a hybrid metaheuristic (OOA-ESSA) that fuses the Osprey Optimization Algorithm (OOA) for exploration with an enhanced Sparrow Search Algorithm (ESSA) for exploitation; candidate feature subsets are encoded as binary vectors, and a fitness function trades off classification accuracy and subset size. Selected features feed a Hybrid Quantum–Classical Convolutional Neural Network (HQCCNN) that replaces some classical convolutional filters with quantum convolutional filters: input windows are encoded into small quantum states (one quantum window per pq qubits), evolved with parametric quantum circuits, and expectation values of observables are used as feature outputs. The HQCCNN loss is minimized using the Boosted Sooty Tern Optimization (BSTO) metaheuristic. The pipeline is evaluated on multi-class ransomware vs normal traffic and compared to several baselines using accuracy, precision, recall, F1-score, specificity, error rate and runtime.

**Algorithms used:** Correlation Coefficient-based Min–Max Normalization (CCMMN), Pearson Correlation Coefficient, Osprey Optimization Algorithm (OOA), Enhancing Sparrow Search Algorithm (ESSA), Hybrid OOA-ESSA (feature selection), Hybrid Quantum–Classical Convolutional Neural Network (HQCCNN), Parametric Quantum Circuit (as quantum convolutional filter), Boosted Sooty Tern Optimization (BSTO)
