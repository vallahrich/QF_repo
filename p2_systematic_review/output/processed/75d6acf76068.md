## Abstract summary
The paper proposes ML-ZNE, a machine-learning-driven zero-noise extrapolation method that uses a hybrid CNN–LSTM to adaptively predict noise-free expectation values from noise-scaled measurements on NISQ devices. By incorporating real-time hardware calibration and adaptive noise scaling, the approach reduces extrapolation error and improves portfolio optimization performance (Sharpe ratio) compared to static ZNE and unmitigated runs.
## Methodology
The authors propose and evaluate a machine-learning-driven zero-noise extrapolation (ML-ZNE) method to mitigate NISQ noise in quantum portfolio optimization. They generate a quantum calibration dataset (synthetic perturbations of hardware calibration parameters) and use a 27-qubit FakeMontreal noise model derived from an IBM Falcon backend to parameterize a density-matrix simulator (Qiskit Aer). Expectation values for cost Hamiltonians are measured at multiple noise scale factors (λ ∈ {1,3,5,7}) using two noise amplification strategies (unitary folding and simplified circuit repetition). These noisy expectation value sequences (per circuit) plus optional calibration features are used as inputs to a hybrid CNN (1D conv) + LSTM network implemented in PyTorch; the network maps sequences of measured <H>(λ) (and calibration tensor) to an estimated zero-noise expectation value (H)0. The CNN-LSTM is trained supervised with pairs of noisy and ideal expectation values using MAE loss, Adam optimizer (lr=1e-4) for 100 epochs. For application-level evaluation, the mitigated expectation values are fed into a QAOA-based mapping of a Markowitz mean-variance portfolio Hamiltonian (6-qubit benchmark circuits, QAOA depth varied including p=4) whose classical parameter optimization uses COBYLA. Baselines are static polynomial ZNE (first/second-order extrapolation) and unmitigated results. Evaluation metrics include mean absolute extrapolation error, changes in QAOA cost landscapes, and portfolio performance (Sharpe ratio). Generalization across circuit depths is tested by comparing ML-ZNE and static ZNE over several depths.

**Algorithms used:** QAOA, Zero-Noise Extrapolation (ZNE), Unitary Folding, Circuit repetition (noise amplification), CNN-LSTM hybrid neural network, COBYLA (classical optimizer for QAOA), Adam (ML optimizer), Richardson/Polynomial extrapolation (static ZNE baseline)
**Frameworks:** Qiskit Aer, PyTorch

**Experimental setup:** Density-matrix simulation using Qiskit Aer with a FakeMontreal (27-qubit Falcon processor) noise model trained on an IBM Quantum backend. Circuits: 6-qubit benchmark QAOA circuits (Hadamard + fixed Z-rotations + nearest-neighbor CX chain) with observable average single-qubit Pauli-Z; noise scaling via unitary folding and circuit repetition; expectation values measured at λ ∈ {1,3,5,7}. ML model trained on synthetic calibration data and simulated noisy/ideal expectation pairs.

**Dataset:** Financial dataset: Fama-French daily returns from 1990-07-02 to 2025-10-31 (9223 samples, 5 features), normalized for portfolio analysis. Quantum dataset: synthetic calibration dataset of 100 samples, each sample a 27×5 feature matrix (T1, T2, readout error, SX error, CX error) with temporal drift simulated via Gaussian perturbations across 10 time steps producing tensors shaped (1,10,27,5).

- [supported] The CNN–LSTM model converged during supervised training on the synthetic calibration/measurement dataset and achieved near-zero training loss in the reported runs.
- [supported] Applying ML-ZNE to QAOA-based portfolio optimization produced expectation-value estimates closer to ideal and yielded higher Sharpe ratios than static ZNE in their experimental setup.

- The financial optimization assumes approximately constant asset returns over the prediction window, which is a simplifying assumption that can reduce effectiveness during regime shifts (author-stated).

## Open questions

- How resilient is ML-ZNE to sudden or large non-stationary changes in noise (e.g., abrupt calibration drift or time-correlated/non-Markovian noise)?

- How effective are learned/adaptive noise-scaling policies (including reinforcement learning) in live deployment compared with supervised ML models?
