## Abstract summary
This paper implements and demonstrates the HHL quantum algorithm on the IBM Qiskit platform, presenting quantum circuits for small-scale (4- and 7-qubit) instances and performing simulation verification. Results show very high fidelity for 2×2 input matrices, and for 4×4 matrices the solver performs well when the matrix is strongly sparse but yields degraded accuracy when sparsity is weak.
## Methodology
The authors implemented and validated the HHL (Harrow-Hassidim-Lloyd) quantum linear system algorithm on the IBM Qiskit platform (Qiskit Aqua). Their workflow was to (1) construct small synthetic linear systems (2x2 and 4x4 matrices) and encode the right-hand side vector |b> as a quantum state, (2) perform quantum phase estimation using Qiskit's EigsQPE routine (Suzuki expansion) to decompose |b> into the eigenbasis of A, (3) apply a controlled rotation implementing the reciprocal of eigenvalues (Lookup reciprocal method) to effect A^{-1} on the amplitudes, (4) apply the inverse phase estimation to uncompute ancilla registers and obtain the solution state |x> proportional to A^{-1}|b>, and (5) extract statevector amplitudes with the statevector simulator and compare them to classical solutions (ExactLSsolver) using the state-fidelity metric. The authors report quantum circuits (for small-qubit examples) and provide example parameter settings used in Qiskit Aqua (expansion_mode='suzuki', expansion_order=2, num_ancillae=3, num_time_slices=50, reciprocal='Lookup', backend=BasicAer statevector_simulator). They test multiple synthetic matrices (diagonal, sparse non-diagonal, and dense symmetric 4x4 matrices) and one 2x2 example, reporting the normalized solution amplitudes and fidelity against the classical solution.

**Algorithms used:** HHL, Quantum Phase Estimation (EigsQPE / QPE), Lookup reciprocal (controlled rotation lookup table), ExactLSsolver (classical solver for baseline comparison)
**Frameworks:** Qiskit, Qiskit Aqua, Qiskit BasicAer (statevector_simulator)

**Experimental setup:** Simulations run in Qiskit Aqua using the BasicAer statevector_simulator. EigsQPE configured with expansion_mode='suzuki', expansion_order=2, num_ancillae=3, num_time_slices=50. Reciprocal implemented via 'Lookup'. Solutions compared to classical ExactLSsolver and fidelities computed with qiskit.quantum_info.state_fidelity.
## Experiment details
### Input
Synthetic linear systems constructed by the authors. Examples: (a) 2x2 matrix A = [[1.5,0.5],[0.5,1.5]] with b = [sqrt(2)/2, sqrt(2)/2]; (b) 4x4 diagonal matrix diag([2,1,3,2]) with b = [1,1,1,1]; (c) 4x4 sparse non-diagonal matrix A = [[2,0,0,1],[1,1,0,0],[0,0,3,0],[1,0,0,2]] with b = [1,0,0,1]; (d) 4x4 real symmetric dense matrix A = [[3,2,1,0],[2,6,4,3],[1,4,2,5],[0,3,5,4]] with b = [1,0,0,1]. The vectors were normalized as quantum states prior to simulation. No external dataset sources were used.

### Process
Pipeline: 1) Prepare |b> on system register (normalize classical b). 2) Run EigsQPE to estimate eigenvalues of A and map eigenvectors to computational basis (parameters: expansion_mode='suzuki', expansion_order=2, num_time_slices=50, num_ancillae=3). 3) Apply controlled rotations using a Lookup reciprocal method to apply 1/λ scaling to amplitudes (implements A^{-1}). 4) Perform inverse QPE to uncompute eigenvalue register. 5) Use statevector simulator to read out solution amplitudes, normalize and compare to classical solution from ExactLSsolver. 6) Compute fidelity via qiskit.quantum_info.state_fidelity. No iterative optimization or shot-based sampling was reported (statevector simulation yields exact amplitudes).

### Output
Outputs were the complex amplitude vectors of the simulated solution state |x> and fidelity scores against classical solutions. Reported metrics: state fidelity (f = |<x_theory|x_exp>|^2). Example reported fidelities: 2x2 case f=1.0000; 4x4 diagonal f=0.999353; 4x4 sparse non-diagonal f=0.823963; 4x4 dense symmetric f=0.653278. Classical baseline used: ExactLSsolver (direct linear solver) for comparison.

- [speculative] The authors state that HHL returns information in the form of a quantum state encoding A^{-1}b (useful for expectation values) rather than returning all components of the classical solution explicitly.

**Results summary:** The authors implemented the HHL algorithm on the IBM Qiskit platform and evaluated it on small instances. They report perfect fidelity for a 2×2 test instance and very high fidelity for a 4×4 diagonal matrix. For a sparse 4×4 non-diagonal matrix fidelity drops but remains moderate (~0.824). For a denser symmetric 4×4 matrix fidelity degrades further (~0.653), leading the authors to conclude HHL performs well for sparse/simple matrices but yields poor accuracy when the input matrix sparsity is weak. No empirical demonstration of algorithmic speedup or scalability beyond these small simulated cases is provided.

## Key ideas
- #idea:near-term-feasibility — Implemented the HHL algorithm on Qiskit using the BasicAer statevector simulator and demonstrated very high fidelity on small instances (2x2 f=1.0000; 4x4 diagonal f≈0.9994), showing feasibility of end-to-end HHL pipelines for toy problems.
- #limitation:simulation-only — All experiments were performed with a statevector simulator (no shot-based runs or real QPU experiments), so hardware noise, sampling error, and gate compilation overheads are not evaluated.
- #limitation:qubit-count — Demonstrations are limited to small circuits (4- and 7-qubit instances including ancillae), highlighting that results are for very small problem sizes and do not demonstrate scalability.
- #contradiction:scalability — Accuracy degrades substantially for less-sparse/dense 4x4 matrices (fidelity ≈0.6533), indicating HHL's practical performance depends strongly on matrix structure and contradicting naive expectations of straightforward applicability to arbitrary dense problems.
- #idea:near-term-feasibility — The paper provides reproducible parameter settings (EigsQPE Suzuki expansion, num_ancillae=3, num_time_slices=50, reciprocal='Lookup') and example matrices, enabling replication and further testing in simulation.
## Contradictions
- The paper demonstrates that HHL yields high-fidelity solutions for small, well-structured (sparse/diagonal) matrices but shows degraded fidelity on dense 4x4 matrices (0.6533), which contradicts any claim that HHL can be directly applied to arbitrary dense linear systems at scale without additional algorithmic or resource overhead.
- Results are simulation-only and do not address noise, sampling, or compilation overheads; therefore the demonstrated fidelities cannot be taken as evidence of near-term advantage on current QPUs, contradicting optimistic extrapolations from simulator-based fidelity to real-hardware performance.
