## Abstract summary
This empirical study investigates integrating quantum-inspired principles (superposition and entanglement) into Reservoir Computing models to improve financial time-series prediction. Using historical AAPL and MSFT data from Yahoo Finance, the author implements a Quantum State Model (QSM) and an Entangled Asset Model (EAM) to estimate marginal and joint movement probabilities and compute inter-asset correlations. The results report probability estimates and simulated predictions, highlighting potential benefits and practical challenges of applying quantum-inspired techniques to capture complex asset interdependencies.
## Methodology
The study is empirical and data-driven. Historical stock prices for Apple (AAPL) and Microsoft (MSFT) were downloaded from Yahoo Finance using the yfinance Python library. Adjusted close prices were converted to daily returns (pct_change) and missing values dropped. Returns were scaled using sklearn's MinMaxScaler for the Quantum State Model (QSM). Two quantum-inspired model representations were prepared: (1) Quantum State Model (QSM) states formed by concatenating the current scaled returns for the assets and a magnitude feature computed as the Euclidean norm of the difference between consecutive return vectors; (2) Entangled Asset Model (EAM) states similarly formed from raw returns with the same magnitude feature to capture joint dynamics. Probabilistic statistics were computed from historical data: per-asset up/down probabilities for QSM and four joint probabilities (up/up, up/down, down/up, down/down) for EAM. A simple correlation-like measure was computed as P(00)+P(11)-P(01)-P(10). Model prediction routines provided in the implementation are placeholders that sample discrete directional forecasts (1 = up, -1 = down) by random choice according to the computed marginal or joint probabilities. Results reported are probability values (P_up, P_down, P_00, P_01, P_10, P_11), the derived correlation, and example sampled prediction/probability pairs. Although the paper frames the work around Reservoir Computing and quantum-inspired ideas (superposition, entanglement), the provided implementation demonstrates data preparation, probability estimation, and a probability-sampling prediction baseline rather than training or evaluating a reservoir or quantum circuit.

**Algorithms used:** Quantum State Model (QSM) — quantum-inspired probabilistic state representation, Entangled Asset Model (EAM) — quantum-inspired joint-probability representation, Reservoir Computing (described conceptually but no reservoir training/implementation present), Probability-based random sampling predictor (placeholder)

**Dataset:** Historical equity prices for Apple (AAPL) and Microsoft (MSFT) retrieved from Yahoo Finance via the yfinance Python library. Adjusted Close prices were used to compute daily returns; two date ranges appear in the manuscript: the Methodology section states 2010-01-01 to 2023-01-01 while the code appendix downloads data from 2000-01-01 to 2024-01-01.

### Reproducibility
The appendix includes an executable Python code snippet that uses yfinance, numpy, pandas and sklearn which is sufficient to reproduce the data download, preprocessing, probability computations and placeholder sampling-based predictions. However, there are inconsistencies between the date range stated in the text and that used in the appendix code. The core implementation does not include an actual Reservoir Computing training routine nor any quantum circuit execution; the QSM/EAM are implemented as data representations and empirical probability estimators. Random sampling is used for predictions but no random seed is set, so sampled prediction sequences will vary between runs unless a seed is added. Overall reproducibility of the reported probability values is high (they derive directly from the downloaded data) but reproducibility of the higher-level claims about RC or quantum-inspired model performance is limited because training/evaluation of such models is not implemented nor are standard evaluation metrics provided.
