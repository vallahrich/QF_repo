## Abstract summary
The paper proposes Q-INN-FD, a quantum-inspired neural network framework that combines quantum-inspired feature encoding, variational quantum circuits (VQCs), and hybrid classical-quantum learning to improve financial fraud detection, risk assessment, and optimization. Experiments claim substantially improved performance over traditional deep learning approaches, reporting higher accuracy (98.91%), reduced false positives (18.33%), and gains in processing efficiency and scalability.
## Methodology
The paper proposes Q-INN-FD (Quantum-Inspired Neural Networks for Fraud Detection), a hybrid classical-quantum fraud detection framework. The pipeline described collects financial transaction data, applies preprocessing (example: StandardScaler), then performs quantum-inspired feature encoding to map classical features into a representation suitable for variational quantum circuits (VQCs). Training is performed in a hybrid classical-quantum manner where VQCs are combined with classical neural network layers; at inference a pre-trained TensorFlow model (referenced as "fraud_detection_model.h5") produces a fraud probability and an auxiliary quantum risk score is computed via a quantum risk assessment module (placeholder function quantum_risk_assessment). Decision logic fuses the two scores using fixed thresholds to output High/Medium/Low risk labels (examples: high risk if fraud_probability>0.7 AND quantum_risk_score>0.8; medium if fraud_probability>0.5 OR quantum_risk_score>0.6). The methodology emphasizes VQCs, quantum-inspired feature transforms, and hybrid training to improve pattern recognition, reduce false positives, and lower computational overhead compared to traditional deep-learning-only approaches. The paper provides a pseudocode algorithm for inference combining a classical TensorFlow model and a quantum risk function, and reports aggregate evaluation metrics (accuracy and false positive rate).

**Algorithms used:** Variational Quantum Circuits (VQC), Quantum-inspired feature encoding, Hybrid classical-quantum learning (classical neural network + VQC), Classical deep neural network (TensorFlow model inference), Standard scaler preprocessing (scikit-learn)
**Frameworks:** TensorFlow, scikit-learn, NumPy, Pandas, Apache Spark, Qiskit, Cirq, PennyLane, Microsoft Quantum Development Kit (QDK), Qiskit-Aer, Amazon Braket, D-Wave Leap, PyTorch, Keras, Python, Matplotlib, QuTiP, TensorBoard
