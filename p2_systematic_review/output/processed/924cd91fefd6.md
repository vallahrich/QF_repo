## Abstract summary
This paper proposes a hybrid quantum-classical framework that integrates Variational Quantum Circuits (VQC) with a classical neural network to detect credit card fraud on an imbalanced transaction dataset. Evaluated on a quantum simulator using the European credit card dataset, the approach encodes features into quantum states and reports strong performance (recall 0.89, precision 0.82, F1 0.85, AUC-ROC 0.91), while noting challenges of noise, scalability, and the need for future real-hardware implementations.
## Methodology
The paper proposes and evaluates a hybrid quantum-classical framework for credit card fraud detection. The methodology begins with standard data cleaning (imputation, standardization, categorical encoding) applied to a publicly available European credit card transactions dataset. PCA-transformed transactional features (V1..V30) plus Time and Amount are used as inputs. Features are encoded for quantum processing (amplitude encoding is used in experiments; angle encoding is discussed as an alternative). Encoded inputs are fed into a parameterized Variational Quantum Circuit (VQC) implemented in a Qiskit-based simulator. The VQC applies layers of parameterized rotation and entangling gates to produce quantum-processed feature representations; measurement yields expectation values/probabilities. These measurement outputs are passed to a classical feedforward neural network (implemented in TensorFlow) that performs final binary classification (fraud vs legitimate). The VQC parameters are optimized in a hybrid training loop using a classical optimizer (Adam) and a weighted loss function to address class imbalance. Experiments are run on a high-performance classical computer using a Qiskit simulator (Python 3.9); the dataset is split 70:30 for training/testing. Performance is reported with precision, recall, F1-score and AUC-ROC.

**Algorithms used:** Variational Quantum Circuit (VQC), Classical feedforward Neural Network (NN), Amplitude encoding, Angle encoding (discussed)
**Frameworks:** Qiskit, TensorFlow, NumPy, Pandas

**Experimental setup:** Experiments were executed on a Qiskit-based quantum simulator running on a high-performance classical computer (Python 3.9). Data preprocessing and PCA were performed classically; amplitude encoding was used to prepare quantum states. The VQC was trained in a hybrid quantum-classical loop with a classical optimizer (Adam) and a weighted loss to handle class imbalance. Data split was 70:30 (train:test).

**Dataset:** European credit card transactions dataset (September 2013) from Kaggle: 284,807 transactions, 492 labeled fraud (≈0.172%). 30 features transformed via PCA (V1..V30); Time and Amount kept untransformed.
