## Abstract summary
The paper presents a Python-integrated hybrid quantum–classical framework using Qiskit to perform time-series prediction via variational quantum circuits coupled with classical optimizers. Experiments on synthetic and real financial data report improved accuracy (93.7% vs 89.3%), lower MSE (0.014) and faster training/execution, and demonstrate a modular, scalable implementation suitable for reproducible hybrid forecasting workflows.
## Methodology
The study designs and implements a Python-integrated hybrid quantum–classical framework for time-series prediction. Time series are windowed and normalized in Python, then individual windows are encoded into quantum states via angle/rotation encoding. These feature-encoded states are fed into variational quantum circuits (VQCs) composed of parameterized rotation gates and entanglement layers. Measurements (expectation values) from the VQC are converted to classical feature vectors which are combined with a classical model. A hybrid loss L_total = alpha * L_quantum + (1-alpha) * L_classical is minimized in a joint training loop: the quantum circuit parameters are updated using gradient estimates (parameter-shift rule) obtained from measurements, while classical weights are updated with gradient-based optimizers (e.g., Adam or SGD). Training is orchestrated entirely within Python (Pandas/NumPy/Qiskit), executed on the Qiskit Aer simulator (with optional cloud backends), and includes hyperparameter tuning (grid/random search), early stopping, checkpointing and logging for reproducibility. Ablation studies disable quantum encoding or vary circuit depth/qubit count to assess contribution of the quantum feature mapping. Baselines (LSTM, GRU, shallow feedforward) are trained with identical preprocessing to enable fair comparison.

**Algorithms used:** Variational Quantum Circuit (VQC), Parameter-shift rule (for quantum gradients), Angle encoding / rotation gate encoding, Entanglement layers, Adam optimizer, SGD optimizer, LSTM (baseline), GRU (baseline)
**Frameworks:** Qiskit, Qiskit Aer (simulator), Python 3.10, NumPy, Pandas

**Experimental setup:** Implementation executed in Python 3.10 using Qiskit (Qiskit Aer simulator) for circuit simulation; experiments run locally with option to switch to cloud quantum runtimes/backends. Containerization and configuration files used for reproducibility. Hyperparameters controlled via config; checkpoints and logging enabled.

**Dataset:** Real financial time series (two cohorts: FIN-Daily — ~30,000 daily aggregated records with window size 60; FIN-Intra — ~120,000 high-frequency intraday records with window size 50) and a synthetic nonlinear dataset (SYN-Nonlin — ~50,000 engineered records, window size 60).
