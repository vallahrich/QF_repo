## Abstract summary
This technical report compares classical and quantum-hybrid machine learning models for binary financial fraud detection using engineered behavioural features on the IBM AML dataset. Classical tree-based ensembles (notably Random Forest and XGBoost) substantially outperform current quantum-hybrid models, though a quantum SVM showed high precision and low false-positive rate at the cost of recall and higher computational overhead. The authors also propose FD4QC, a pragmatic API-driven deployment architecture that adopts a "classical-first, quantum-enhanced" approach with robust fallbacks.
## Methodology
The study compares classical and quantum-hybrid supervised classifiers for binary financial fraud detection. Experiments use a reduced, undersampled version of the synthetic IBM Transactions for Anti-Money Laundering (AML) dataset. A behavioural feature engineering pipeline was applied to transform raw transaction records into tabular features: statistical aggregates by account role (mean, std, min, max), temporal dynamics (time-since-last, EWMA), categorical/contextual one-hot encodings (currency, format, same_bank, self-loop), behavioural-change indicators, and pairwise statistics including a Pair_Equilibrium metric. Classical baselines (Logistic Regression, Decision Tree, Random Forest, XGBoost) were trained on these features. Three quantum-hybrid architectures were implemented with PennyLane and its scikit-learn / PyTorch integrations: a quantum-kernel Support Vector Classifier (QSVC) using quantum circuits to compute kernels, a Variational Quantum Classifier (VQC) comprising a quantum feature map, parametrised ansatz and classical optimiser, and a Hybrid Quantum Neural Network (HQNN) which places a variational quantum circuit as a hidden layer inside a classical network (classical encoder → quantum layer → classical classifier). Models were trained/evaluated on a holdout test set with a maintained class ratio of 9:1 (non-suspicious : suspicious). Performance was measured using Accuracy, F-measure, Precision, Recall and False Positive Rate. No real quantum hardware was used; implementations were executed via PennyLane-compatible simulators and are written to be deployable on actual devices when available. The overall system design (FD4QC) is a stateless RESTful API implementing a "classical-first, quantum-enhanced" routing with automatic fallback to classical surrogates when quantum backends are unavailable.

**Results summary:** On a reduced, undersampled IBM AML synthetic dataset (9:1 class ratio), classical ensemble methods (Random Forest, XGBoost) substantially outperformed the evaluated quantum-hybrid models. Random Forest achieved the best overall performance. Among the quantum-inspired approaches, a quantum-kernel method (QSVC) achieved notably high precision and a very low false-positive rate but suffered from low recall and longer computational times. Variational quantum models (VQC) and the tested HQNN variants failed to reliably detect the positive (fraudulent) class. The authors therefore conclude that, in this experimental setting, quantum ML is not yet mature enough to beat classical methods, while proposing an FD4QC API architecture and several speculative research directions to improve future viability.
