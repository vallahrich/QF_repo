## Abstract summary
This paper surveys major quantum computing frameworks and toolkits (e.g., Qiskit, Microsoft QDK/Q#, Cirq, Rigetti Forest/PyQuil, PennyLane/Strawberry Fields, ProjectQ, QuTiP, Intel SDK, and cloud services such as Amazon Braket and Azure Quantum). It compares language support, hardware backends, open-source status, typical use cases, and deployment trade-offs, provides short example circuits and integration notes, and offers practical guidance for selecting frameworks based on developer background and project needs.
## Methodology
This paper proposes a Dynamic Cloud Task Clustering (DCTC) approach for orchestrating and scheduling scientiﬁc workﬂows in dynamic cloud environments. Workﬂows are modeled as Directed Acyclic Graphs (DAGs). DCTC iteratively clusters tasks level-by-level (from deepest level upward), using task properties (e.g., parent runtimes, in-degree) to form clusters that balance parallelism and scheduling overhead. When the number of clusters exceeds a target resource set size r, a reduction step produces a reduced cluster set to match available resources. The approach reuses candidate optimal schedules from prior ordinal-optimization work to guide cluster-to-VM mapping and minimize makespan. To evaluate DCTC, the authors run extensive simulations using WorkﬂowSim on multiple real scientiﬁc workﬂows (e.g., Montage, CyberShake and others), compare against baseline clustering strategies (Horizontal Clustering, Horizontal Runtime Balancing, Horizontal Impact-Factor Balancing, Horizontal Distance Balancing), and measure performance gains (μ), makespan, resource consolidation and runtime under different VM counts and workload characteristics.

**Algorithms used:** Dynamic Cloud Task Clustering (DCTC), Ordinal Optimization (for candidate schedule generation), Horizontal Clustering (baseline), Horizontal Runtime Balancing (baseline), Horizontal Impact-Factor Balancing (baseline), Horizontal Distance Balancing (baseline)
**Frameworks:** WorkﬂowSim

**Experimental setup:** Simulations were executed with WorkﬂowSim (a cloud workﬂow simulator). Experiments used four scientiﬁc workﬂows (including Montage and CyberShake) executed over a range of virtual machine (VM) counts to evaluate makespan, resource consolidation and performance improvement (μ). The DCTC algorithm was compared against four baseline clustering methods using identical workﬂow inputs and cloud settings.
