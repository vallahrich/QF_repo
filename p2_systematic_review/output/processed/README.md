# `output/processed/` — Per-paper classified Markdown profiles

The canonical Phase 2 deliverable. One pair of files per paper:

- `<paper_id>.md` — human-readable structured profile (frontmatter + 6 narrative sections).
- `<paper_id>_extraction.json` — machine-readable companion with the same fields plus extraction metadata.

`<paper_id>` is the 12-hex-char hash from [`shared/bridge/paper_id_bridge.csv`](../../../shared/bridge/paper_id_bridge.csv).

## Volume

777 papers (pre-triage). 22 are formally excluded post-hoc — see [`../audit/excluded_post_classification.csv`](../audit/excluded_post_classification.csv).

## Generated by

[`../../s2_classification/scripts/extract_paper.py`](../../s2_classification/scripts/extract_paper.py) via `run_classification.py`, using the 6-step cached-prefix prompts in [`../../s2_classification/prompts/`](../../s2_classification/prompts/).

## Downstream

Consumed by Phase 3 silo scoping ([`p3_thematic_synthesis/s1_silo_scoping/`](../../../p3_thematic_synthesis/s1_silo_scoping/)) and quantitative extraction.
