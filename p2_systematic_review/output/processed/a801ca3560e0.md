## Abstract summary
This preprint evaluates Quantum Support Vector Machines (QSVM) on a real-world financial dataset for stock market classification, implementing a Cirq-based quantum feature map and kernel and comparing QSVM performance to a classical SVM. Results show modest accuracy gains (85% vs 82%) and potential training-time improvements for small instances but emphasize major limitations due to quantum circuit depth, scalability, noise, and resource requirements, recommending hybrid quantum-classical approaches and further hardware and algorithmic development.
## Methodology
The paper implements a Quantum Support Vector Machine (QSVM) by mapping classical input vectors into quantum states via a simple quantum feature map implemented as a small Cirq circuit, computing a quantum kernel as the squared overlap of the resulting statevectors, and feeding the resulting precomputed kernel matrix into a classical SVM (sklearn.SVC with kernel='precomputed'). The workflow in the experiment: generate a dataset (in the provided code a synthetic binary dataset), build a 2-qubit quantum circuit per sample (Hadamard gates followed by conditional CNOT(s) driven by input bits), simulate each circuit with Cirq.Simulator to obtain statevectors, compute pairwise kernel entries K(x,y)=|⟨ϕ(x)|ϕ(y)⟩|^2 to assemble training and test kernel matrices, train the classical SVM on the quantum kernel, and evaluate test accuracy against a baseline classical SVM. The paper also discusses circuit depth, scalability and noise as limiting factors and compares QSVM performance (accuracy and claimed training time) to a classical SVM baseline.

**Algorithms used:** Quantum Support Vector Machine (QSVM), Classical Support Vector Machine (SVM), Quantum kernel estimation (statevector overlap)
**Frameworks:** Cirq, NumPy, scikit-learn

**Experimental setup:** Statevector simulation using cirq.Simulator on classical hardware. Circuits use 2 qubits per sample (Hadamard gates plus conditional CNOTs based on input bits). Quantum kernel computed as squared absolute overlap of simulated statevectors and used as a precomputed kernel in sklearn.SVC.

**Dataset:** Although the paper frames the work as applying QSVM to financial data, the actual experiment shown in the code uses a synthetic dataset: 100 samples with 2 binary features (X sampled with np.random.randint(0,2,size=(100,2))) and binary labels y randomly sampled (np.random.randint(0,2,size=100)).
