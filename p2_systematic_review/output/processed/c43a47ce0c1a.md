## Abstract summary
The paper proposes a hybrid quantum-classical fraud detection method that encodes reduced classical features into quantum states using angle encoding (Qiskit QuantumCircuit) and classifies transactions with a Quantum Neural Network combined with classical neural network layers. Evaluated on a credit-card fraud dataset, the approach reports 92% overall accuracy and achieves 0.65 precision and 0.68 recall for the fraud class, employing sampling strategies (SMOTE/RandomOverSampler) and GridSearchCV for hyperparameter tuning.
## Methodology
The study uses a hybrid quantum-classical pipeline for fraud detection. Raw transaction data are preprocessed (min-max normalization for numerical features, categorical encoding for fields such as CODE_GENDER and FLAG_OWN_CAR, and forward/backward fill for missing values). A classical multi-layer neural network is trained for dimensionality reduction (dense layers with sizes [64, 32, 16, 10, 8, 4], ReLU activations) and the activations from the second-to-last layer (16-neuron representation, referred to as h(16)) are extracted as reduced features. These 16 features are angle-encoded into a quantum circuit (each feature hi mapped to a qubit using a U3 gate with θi = π·hi). QuantumCircuit (Qiskit) constructs the circuit: Hadamard gates put qubits into superposition, Controlled-Z gates introduce entanglement, and a measurement step yields the quantum state vector / density matrix and measurement counts. The resulting quantum state vectors |ψ⟩ are fed into a classical neural network classifier (dense layers with ReLU and a final sigmoid output) — referred to as a Quantum Neural Network (QNN) in the paper — trained by backpropagation. Class imbalance is handled with oversampling strategies (SMOTE and RandomOverSampler). Hyperparameter tuning is performed with GridSearchCV to select learning rate, optimizer, dropout and other training parameters. Performance is evaluated using accuracy, precision, recall, F1-score, confusion-matrix-derived statistics, and circuit-level diagnostics (density matrix, measurement histograms, and average circuit depth).

**Algorithms used:** Quantum Neural Network (QNN) - hybrid quantum-classical, Angle encoding (U3 gate based), Hadamard superposition, Controlled-Z (CZ) entanglement, Classical multi-layer neural network (for dimensionality reduction), Classical neural network classifier (dense layers with sigmoid output), SMOTE (Synthetic Minority Over-sampling Technique), RandomOverSampler, GridSearchCV (hyperparameter tuning)
**Frameworks:** Qiskit, scikit-learn (GridSearchCV, metrics), imbalanced-learn (SMOTE, RandomOverSampler)

**Experimental setup:** Quantum circuits were constructed and simulated via Qiskit. Features reduced to 16 dimensions were angle-encoded using U3 gates (θ = π·hi) across qubits; Hadamard gates applied to each qubit and CZ gates used to entangle qubits. Measurements produced state vectors / density matrices and measurement counts. Average circuit depth reported for first 10 records: 7.3. Classical networks trained with backpropagation; hyperparameters tuned via GridSearchCV. Class imbalance handled by SMOTE/RandomOverSampler.

**Dataset:** Credit Card Fraud Detection dataset (financial transactions). The dataset contains 284,807 transactions of which 492 are fraudulent (highly imbalanced).
