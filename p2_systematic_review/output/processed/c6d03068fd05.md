## Abstract summary
The paper introduces QFNN-FFD, a framework that combines quantum machine learning (a variational quantum neural network) with federated learning to detect financial fraud while preserving client data privacy. Evaluated on the IEEE-CIS Fraud Detection dataset using PennyLane and Qiskit noise simulators, the approach reports high performance (≈95% accuracy/precision) and examines robustness across six quantum noise models, demonstrating practical viability for near-term quantum-enhanced, privacy-preserving fraud detection.
## Methodology
The authors propose QFNN-FFD, a hybrid quantum-classical federated learning framework that trains a variational Quantum Neural Network (QNN) in a decentralized manner across multiple clients to detect financial fraud. Classical transaction data (numerical and categorical) are preprocessed (data-type memory optimization, missing-value analysis, categorical one-hot encoding, numerical standardization, and class up-sampling) and split IID across 15 clients. Each client encodes its local classical feature vectors into quantum states using angle encoding (mapping features to Ry and Rz rotations), prepares entanglement via a chain of CNOT gates, applies a parametrized variational circuit (the QNN) and measures output observables to produce classical predictions. Local training minimizes Mean Squared Error (MSE) using the Adam optimizer (learning rate 0.1) and gradients computed with the parameter-shift rule. After local optimization (up to 100 iterations), clients send optimized parameters to a central server which aggregates parameters via federated averaging to update the global model; the global parameters are redistributed for further local refinement. Experiments are performed using PennyLane for circuit construction and simulation, and Qiskit noise simulators (six noise channels) to evaluate noise robustness. Performance is evaluated via accuracy, precision, recall, F1-score and MSE loss and compared to a centrally trained QNN baseline as well as selected QML literature baselines.

**Algorithms used:** Variational Quantum Neural Network (QNN), Quantum Federated Learning (federated averaging), Angle encoding (Ry, Rz), CNOT entanglement chain, Parameter-shift rule for quantum gradients, Adam optimizer
**Frameworks:** PennyLane, Qiskit

**Experimental setup:** PennyLane quantum simulator for quantum circuit emulation; Qiskit noise simulators (IBM) for six quantum noise models (bitflip, phaseflip, bitphaseflip, depolarizing, amplitude damping, phase damping). Experiments used 15 federated clients, up to 100 training iterations, averaged over 10 trials for reported validation metrics. Host compute: 4 vCPUs, 25 GB RAM, one NVIDIA Tesla V100 vGPU.

**Dataset:** IEEE-CIS Fraud Detection dataset (transaction and identity files joined by TransactionID). Dataset contains both numerical and categorical features relevant to fraud detection; total reported instances in experiments: 144,233 (after preprocessing).

### Process
1) Preprocess full dataset and split IID among 15 clients (80/20 train/validation split). 2) On each client: for each batch, encode classical features into quantum states via angle encoding (feature -> Ry and Rz rotations), apply parametrized QNN layers interleaved with a chain of CNOT entangling gates, measure qubits to obtain classical outputs. 3) Compute MSE loss between outputs and labels. 4) Compute gradients using the parameter-shift rule and update local parameters with Adam (η=0.1). 5) Repeat local optimization up to T=100 iterations (early stopping if converged). 6) Send optimized local parameters to central server; aggregate via simple average to form global parameters and broadcast back to clients. 7) Evaluate global model on validation set; repeat global-local cycles. 8) Perform noise robustness experiments by simulating six quantum noise channels via Qiskit with noise parameter sweep from 0 to 1. 9) Report metrics averaged over 10 trials.
