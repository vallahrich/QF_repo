## Abstract summary
The paper proposes OptSHQCNN, a two-phase (pre-deployment and post-deployment) deep learning framework for phishing detection that combines advanced preprocessing, attention-based feature extraction (CBAM), metaheuristic feature selection (Red Kite Optimization), and a shallow hybrid quantum-classical CNN (SHQCNN) whose hyperparameters are tuned with a shuffled shepherd optimizer. Post-deployment URL encoding uses an optimized BERT and the system achieves very high performance (above 99% on accuracy, precision, recall and F1) across multiple benchmark phishing URL datasets.
## Methodology
The study proposes a two-phase (pre-deployment and post-deployment) hybrid deep-learning pipeline (OptSHQCNN) for URL-based phishing detection. In the pre-deployment phase the authors perform data cleaning (removal of invalid and redundant features and handling missing values), address class imbalance using a combined Self-Paced Ensemble (SPE) undersampling + Auxiliary Classifier GAN (ACGAN) oversampling approach (SPE-ACGAN), extract deep features from page code and URLs using a Convolutional Block Attention Module (CBAM), and then apply a metaheuristic feature selection algorithm (Red Kite Optimization Algorithm, RKOA) to select a compact discriminative feature subset. Classification is performed by a Shallow Hybrid Quantum–Classical Convolutional Neural Network (SHQCNN) in which a simulated Variable Quantum Circuit (VQC) / kernel-encoding layer (RY/RZ rotations, entanglement layers) is used as a quantum-inspired feature transformation followed by classical CNN/fully-connected layers. Hyperparameters of the SHQCNN are tuned with a metaheuristic Shuffled Shepherd Optimization Algorithm (SSOA). In the post-deployment phase URLs are encoded using an optimized BERT variant (OptBERT) to produce contextual embeddings which are passed into the trained classifier for inference. Experiments compare the approach to multiple classical and deep-learning baselines and report standard classification metrics (accuracy, precision, recall, F1, MCC, FPR). The quantum component is simulated on classical hardware (no real QPU was used).

**Algorithms used:** ACGAN, Self-Paced Ensemble (SPE), Convolutional Block Attention Module (CBAM), Red Kite Optimization Algorithm (RKOA), Shallow Hybrid Quantum-Classical CNN (SHQCNN), Variable Quantum Circuit (VQC) / kernel encoding (RY, RZ, entanglement gates), Shuffled Shepherd Optimization Algorithm (SSOA), OptBERT (fine-tuned BERT for URL encoding), CNN, LSTM, Random Forest, GradientBoost/LightGBM (as baselines), Adam/Adamax/SGD/RMSprop/Nadam (optimizers compared)
**Frameworks:** TensorFlow, Keras, Python (Anaconda3), joblib

**Experimental setup:** Experiments ran on a Windows 10 desktop with an Intel Core i5 CPU @ 2.60 GHz and 16 GB RAM. The quantum-inspired circuit (VQC) was simulated on classical hardware (no QPU). Models were implemented in Python using TensorFlow/Keras. Cloud inference testing used an AWS instance (RESTful service). Training used batch sizes in experiments up to 64, with early stopping and metaheuristic hyperparameter tuning (SSOA).

## Findings
- [supported] The proposed OptSHQCNN pipeline (pre-deployment CBAM feature extraction + RKOA feature selection + SHQCNN classification tuned by SSOA, with post-deployment OptBERT URL encoding) attains very high phishing-detection performance across multiple benchmark datasets.
- [supported] Using SPE-ACGAN for class imbalance (oversampling minority phishing class and undersampling majority) improved recall and F1 for phishing class relative to conventional rebalancing.
- [supported] The convolutional block attention module (CBAM) effectively extracts discriminative features from URLs and webpage code for phishing detection.
- [supported] The red kite optimization algorithm (RKOA) for feature selection reduces the feature set and yields low computation time while maintaining high accuracy.
- [supported] The shuffled shepherd optimization algorithm (SSOA) for hyperparameter tuning produced better classifier results than standard optimizers (Adam, SGD, etc.) in the experiments reported.
- [supported] The full proposed system reports very low inference latency suitable for real-time use (inference times under ~1.1 ms per sample on the reported hardware/cloud), and a reported average cloud request completion of 11.5 microseconds for a specific server setup.
- [supported] Extensive experiments on four datasets (Mendeley_2020, ISCX-URL-2016, URL-Based Phishing Dataset, PhishStorm) show consistently high accuracy and balanced precision/recall, indicating generalizability across those datasets.
- [supported] Ablation experiments indicate that each pipeline component (preprocessing, imbalance handling, feature extraction, feature selection, classification, URL encoding) contributed incrementally to the final performance.
- [speculative] The SHQCNN hybrid quantum-classical architecture (VQC kernel encoding + shallow quantum circuit + classical CNN layers) provides a representational and computational benefit (improved separability and lower space complexity) compared to fully classical models.
- [speculative] Kernel-based quantum encoding can reduce spatial complexity to approximately O(N/2) qubits for N classical features, improving distinguishability in high-dimensional spaces.
- [speculative] Quantum-inspired components (VQC, variable quantum circuits, and multi-output quantum measurement layers) can reduce model depth/parameters while approximating nonlinear functions and improving robustness on NISQ-style devices.
- [speculative] Integrating OptBERT for URL encoding in a post-deployment cloud service enhances contextual feature representation and supports accurate predictions in production.
- [disputed] The paper implies a concrete quantum computational advantage (speed or accuracy) from inserting quantum layers; however, no experiments on real quantum hardware were reported and the 'quantum' components were simulated classically, so the asserted practical computational advantage is not empirically demonstrated.

## Quantum advantage claim
**Classification:** speculative

The authors claim representational and complexity benefits from hybrid quantum-classical modules (VQC, kernel encoding, multi-output quantum layers) and assert improved separability and lower space complexity. However, all quantum components were simulated on classical hardware and no experiments on actual quantum processors were provided; therefore a practical quantum advantage is speculative rather than demonstrated.
## Limitations
- The quantum component was not executed on real quantum hardware; the variable quantum circuit (VQC) / quantum layers were simulated on classical hardware rather than run on NISQ devices.
- The model does not verify whether a target website is actually live/reachable by inspecting the URL, which can affect prediction correctness.
- The work focuses primarily on URL-based features and gives limited consideration to other informative modalities such as webpage visual similarity and user interaction/behaviour signals.
- [inferred] No experimental demonstration of a practical quantum advantage: because all quantum parts were simulated classically, it remains unproven whether the SHQCNN design yields runtime or accuracy benefits on real quantum hardware.
- [inferred] Feasibility constraints on real quantum implementation (qubit count, circuit depth, noise): mapping high-dimensional URL data into quantum states and running the VQC on current NISQ machines may be impractical or noisy.
- [inferred] Encoding and readout overheads: the kernel encoding and multi-output quantum readout steps may introduce substantial preprocessing/communication overheads that were not evaluated on real quantum systems.
- [inferred] Potential generalization and robustness concerns: extremely high reported metrics (≈99%+) risk being optimistic if the approach overfits to the selected datasets or to properties reproduced by ACGAN-generated synthetic phishing samples.
- [inferred] Dependence on synthetic oversampling (ACGAN / SPE-ACGAN): generated phishing samples may not fully capture real-world attacker behaviour, which could bias training and evaluation.
- [inferred] Novel metaheuristics (RKOA, SSOA) are introduced but reproducibility and sensitivity to hyperparameters across other datasets/environments was not deeply explored.
- [inferred] Limited multimodal integration: other useful signals (page screenshots, JavaScript behavior, TLS certificate details beyond presence of HTTPS, email metadata) were not incorporated.
- [inferred] Explainability and interpretability of the hybrid quantum-classical model are not addressed; it may be hard to interpret why a sample is classified as phishing.
- [inferred] Privacy, deployment and resource considerations (compute, memory, energy) of the full pipeline (OptBERT + CBAM + SHQCNN + optimizers) when deployed at scale or on edge devices were not evaluated.
## Open questions
- Can the SHQCNN architecture deliver a measurable quantum advantage (accuracy, training/inference speed, or compactness) when executed on real quantum hardware (NISQ devices) versus purely classical baselines?
- How resilient is the hybrid quantum-classical model to quantum device noise, limited qubit counts, and realistic constraints on circuit depth?
- What are the practical costs (latency, energy, monetary) of encoding URL data into quantum states and performing multi-output quantum readouts in production environments?
- How well does the approach generalize to unseen, actively evolving phishing campaigns or to domains/languages not represented in the training datasets?
- How realistic and representative are the ACGAN-generated phishing samples compared to real attacker-generated phishing URLs, and how does that affect real-world detection performance?
- How does the model perform under adversarial manipulation of URLs (targeted obfuscation, homoglyphs, adversarial examples) and can the quantum component improve adversarial robustness?
- What is the impact of integrating additional modalities (visual page similarity, rendered HTML/DOM behavior, user-interaction traces) into the hybrid framework?
- How can the SHQCNN and the novel optimizers (RKOA, SSOA) be made interpretable so security teams can understand and act on detections?
- What are the privacy and compliance implications of using large pretrained models (OptBERT) and synthetic data generation in operational phishing detection pipelines?
- How feasible is real-time deployment of the full pipeline (including OptBERT encoding and the quantum-inspired layers) on resource-constrained edge devices such as browser plugins or mobile clients?

**Future work:**
- Enhance feature engineering and speed up the training process to enable verification of a website's live/current status and improve training correctness.
- Incorporate additional informative aspects beyond URL features—specifically visual similarity of web content and user interaction behaviour—to further improve detection in complex phishing scenarios.

- #idea:hybrid-approach — Two-phase pipeline (pre-deployment classical preprocessing: SPE-ACGAN balancing, CBAM feature extraction, RKOA selection; post-deployment OptBERT encoding) integrates a shallow simulated quantum layer with classical CNN/dense layers and metaheuristic hyperparameter tuning (SSOA).
- #contradiction:classical-vs-quantum — The quantum component is simulated on classical CPU and the pipeline includes extensive classical feature engineering and balancing; therefore reported gains may be due to classical components rather than a true quantum advantage.

## Contradictions
- The paper attributes improved detection performance to the hybrid quantum-classical SHQCNN, yet the quantum layer was only simulated on a classical CPU and heavy classical preprocessing (SPE-ACGAN, CBAM, RKOA, OptBERT) likely explains most gains — this contradicts any strong claim of quantum superiority (contradiction:classical-vs-quantum).
- Authors claim favorable scaling/resource behaviour (e.g., spatial complexity O(N/2) to map features to qubits) but provide no qubit counts, circuit depths, shot counts, or real-QPU experiments and also report inconsistent hyperparameter values — this contradicts claims about practical scalability and reproducibility (contradiction:scalability).
