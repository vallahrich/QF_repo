## Abstract summary
The paper proposes a continuous-variable quantum K-Means (CVQK-Means) algorithm that encodes classical data into photonic Gaussian states and performs clustering using quantum interference and homodyne detection, implemented with the Strawberry Fields platform. The authors demonstrate prototypes on Iris, Wine, and synthetic datasets, reporting clustering performance comparable to classical K-Means while discussing noise, scalability limitations, and directions for hardware and algorithmic improvements.
## Methodology
The authors design and implement a Continuous-Variable Quantum K-Means (CVQK-means) clustering procedure that encodes classical data points as photonic Gaussian states using displacement and squeezing operations. Each data point xi is prepared as |ψ(xi)⟩ = D(αi) S(r) |0⟩ with a fixed squeezing parameter r and a displacement αi derived from the data coordinates. Distances between data points and centroids are computed via the overlap between Gaussian states, estimated by interfering states on beam splitters and measuring quadratures with homodyne detection; the overlap-based distance used is D(xi, ck) = 1 − |⟨ψ(xi)|ψ(ck)⟩|^2. The CV K-means loop follows the classical K-means structure: encode data, initialize K centroid states, assign points to nearest centroid via the quantum-measured overlaps, update centroids by superposing (summing and normalizing) the assigned quantum states, and iterate until centroid changes fall below a threshold or a maximum iteration count is reached. The algorithm was implemented using the Strawberry Fields platform and executed on (or simulated with) Xanadu’s photonic hardware/software stack. Evaluation was performed on Iris, Wine and a synthetic dataset and compared against classical K-means using clustering accuracy and sum-of-squared-distances (SSD) as primary metrics.

**Algorithms used:** Continuous Variable Quantum K-Means (CVQK-means), Classical K-Means (baseline)
**Frameworks:** Strawberry Fields

**Experimental setup:** Implementation used Xanadu’s Strawberry Fields platform for photonic continuous-variable quantum computation, leveraging Gaussian-state preparation (displacement and squeezing), linear optics (beam splitters/phase shifters) for interference, and homodyne detection to estimate overlaps. Experiments were reported on Xanadu photonic hardware/simulator via Strawberry Fields.
