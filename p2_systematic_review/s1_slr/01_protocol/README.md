# `s1_slr/01_protocol/` — SLR protocol & PRISMA checklists

| File | Purpose |
|------|---------|
| `protocol.md` | The active SLR protocol (Kitchenham & Charters, 2007). Authoritative scope, search strategy, inclusion/exclusion criteria. |
| `PRISMA_2020_checklist.md` | PRISMA 2020 reporting checklist. |
| `PRISMA_S_checklist.md` | PRISMA-S search reporting extension. |
| `amendments_log.csv` | Append-only log of dated amendments to the protocol. |
| `amendments/` | Full text of each amendment. See [`amendments/README.md`](amendments/README.md). |

## Status

The protocol is frozen as published; amendments add controlled scope changes (e.g. the 2026-05-02 post-classification triage). Each amendment must be referenced in the manuscript Methodology chapter.
