## Instructions

You are a research assistant identifying contradictions between papers in the same problem silo for a systematic literature review on quantum computing in financial services.

## Inputs

### Paper memos (approved A2 memos from within this silo)
{silo_memos}

## Task

Compare the claims across these paper memos. Identify pairs of papers where:
- One paper claims X and another claims NOT-X (true contradiction)
- One paper reports result A and another reports a significantly different result A' for the same problem/method (contested result)

IMPORTANT: Distinguish between:
- **True contradictions**: genuinely incompatible claims about the same phenomenon
- **Incomparable setups**: different results that arise from different problem sizes, hardware, datasets, or algorithmic variants (NOT contradictions)

## Output Format

Return a JSON array of contradiction entries:

```json
[
  {{
    "contradiction_id": "CTR-001",
    "type": "true_contradiction|contested_result",
    "paper_a": "{paper_id_a}",
    "claim_a": "<specific claim from paper A>",
    "paper_b": "{paper_id_b}",
    "claim_b": "<specific claim from paper B>",
    "tension": "<1-2 sentence description of the tension>",
    "incomparable_factors": "<factors that might explain the difference, or 'none'>",
    "severity": "high|medium|low"
  }}
]
```

If no contradictions are found, return an empty array `[]`.

Focus on substantive claims about quantum advantage, performance, scalability, and feasibility. Do NOT flag contradictions about terminology preferences, citation choices, or framing differences.

Output ONLY the JSON array. No markdown wrapping.
