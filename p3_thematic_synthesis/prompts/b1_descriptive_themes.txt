## Instructions

You are a research assistant identifying descriptive themes from a batch of analytical memos for a systematic literature review on quantum computing in financial services.

## Inputs

### Silo context
Silo: {silo_name} ({silo_code})
Papers in this batch: {batch_size}

### Paper memos (approved A2 memos, batch of ~20-30)
{batch_memos}

## Task

Read all memos in this batch. Identify recurring descriptive themes — patterns that appear across multiple papers. A theme must be supported by at least {min_papers_per_theme} papers.

Descriptive themes answer: "What does the literature say about this topic?" They describe patterns, not interpret them.

## Output Format

Return a JSON array of themes:

```json
[
  {{
    "theme_id": "DT-{silo_code}-001",
    "theme_label": "<short descriptive name, 5-10 words>",
    "description": "<2-3 sentence description of the theme>",
    "supporting_papers": ["{paper_id_1}", "{paper_id_2}", "{paper_id_3}"],
    "evidence_summary": "<key evidence across the supporting papers>",
    "dimension_cluster": "<which memo dimensions contribute most to this theme>"
  }}
]
```

RULES:
1. Each theme must cite >= {min_papers_per_theme} papers from this batch.
2. Themes must be DESCRIPTIVE (what the papers say), not ANALYTICAL (what it means).
3. Do not create themes that merely repeat Phase 2 classification categories.
4. If a pattern appears in only 1 paper, it is a finding, not a theme — do not include it.

Output ONLY the JSON array. No markdown wrapping.
