## Instructions

You are a research assistant identifying cross-silo patterns for a systematic literature review on quantum computing in financial services.

## Inputs

### All silo theme sets (B2 analytical themes from all 8 silos)
{all_silo_themes}

### Existing contradiction register
{cross_cutting_contradictions}

### Bibliometric landscape data
{bibliometric_summary}

## Task

Compare theme sets across all silos. Identify:

1. **Shared themes** — analytical themes that appear in >= 3 silos (genuine cross-cutting pattern)
2. **Silo-unique themes** — themes that appear in only 1-2 silos (domain-specific finding)
3. **Cross-silo contradictions** — claims in one silo that conflict with claims in another
4. **Method migration patterns** — the same quantum method (SA code) appearing across different problem silos over time

## Output Format

Return a JSON object:

```json
{{
  "shared_patterns": [
    {{
      "pattern_id": "SP-001",
      "pattern_label": "<descriptive name>",
      "description": "<2-3 sentences>",
      "silos_involved": ["PD-01", "PD-03", "PD-09"],
      "evidence_themes": ["AT-PD01-002", "AT-PD03-001", "AT-PD09-004"],
      "significance": "<why this pattern matters>"
    }}
  ],
  "silo_unique_findings": [
    {{
      "finding_id": "UF-001",
      "silo": "PD-06",
      "theme": "AT-PD06-001",
      "description": "<why this is unique to this silo>",
      "possible_explanation": "<why doesn't it appear elsewhere?>"
    }}
  ],
  "cross_silo_contradictions": [
    {{
      "contradiction_id": "XC-001",
      "silo_a": "PD-01",
      "claim_a": "<claim>",
      "silo_b": "PD-04",
      "claim_b": "<conflicting claim>",
      "tension": "<description of the tension>",
      "resolution_hint": "<possible explanation>"
    }}
  ],
  "method_migrations": [
    {{
      "method": "<algorithm/approach name>",
      "origin_silos": ["PD-02"],
      "adopted_silos": ["PD-01", "PD-09"],
      "pattern": "<description of the migration>"
    }}
  ]
}}
```

RULES:
1. Only flag shared patterns with genuine cross-silo evidence (>= 3 silos).
2. Cross-silo contradictions must be substantive — not just different contexts.
3. Candidate patterns only — the researcher adjudicates in C2.

Output ONLY the JSON object. No markdown wrapping.
