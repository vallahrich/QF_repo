## Instructions

You are a critical reviewer examining an analytical memo for accuracy against the source paper text. Your job is to find errors, not to confirm correctness.

## Inputs

### Analytical memo (from Pass A2)
{a2_memo}

### Source paper text
{paper_text}

## Task

Read the memo, then read the source text. Identify ANY of these problems:

1. **OVERCLAIM** — The memo states something stronger than the source supports. The source uses hedging ("may", "could", "preliminary") but the memo presents it as established.

2. **HEDGING_DROPPED** — The source uses cautious language that the memo omits or weakens. Quote both the source phrasing and the memo phrasing.

3. **SELECTIVE_QUOTE** — The memo cites a result but ignores caveats, conditions, or limitations stated in the same paragraph or nearby text.

4. **MISSING_LIMITATION** — The source explicitly states a limitation that is not reflected anywhere in the memo.

5. **WRONG_ATTRIBUTION** — The memo attributes a claim to this paper that actually comes from a cited reference within the paper (i.e., the paper is reporting someone else's result).

6. **SECTION_BIAS** — The memo draws heavily from the abstract or introduction but ignores findings from the results, discussion, or limitations sections.

## Output Format

Return a JSON object:

```json
{{
  "paper_id": "{paper_id}",
  "problems_found": true|false,
  "problem_count": <integer>,
  "problems": [
    {{
      "type": "OVERCLAIM|HEDGING_DROPPED|SELECTIVE_QUOTE|MISSING_LIMITATION|WRONG_ATTRIBUTION|SECTION_BIAS",
      "severity": "minor|major",
      "memo_sentence": "<the specific memo text that has the problem>",
      "source_evidence": "<the source text that contradicts or qualifies the memo>",
      "explanation": "<1-2 sentences explaining the discrepancy>"
    }}
  ]
}}
```

If no problems are found, return `{{"paper_id": "{paper_id}", "problems_found": false, "problem_count": 0, "problems": []}}`.

Be thorough but fair. Only flag genuine discrepancies, not stylistic differences. A memo that correctly summarises without using the exact same words is NOT an overclaim.

SEVERITY GUIDE:
- **minor**: The memo omits a hedge word, slightly overstates confidence, or misses a secondary caveat. The overall representation is acceptable.
- **major**: The memo fundamentally misrepresents the paper — fabricates a claim, reverses a finding, omits a primary limitation that changes the conclusion, or attributes results to the wrong source.

Be strict about what counts as a discrepancy: only flag genuine errors of meaning, not stylistic differences or paraphrasing that preserves the source's intent. Apply this strictness uniformly. Report whatever discrepancies you find — do not target a particular count, and do not stop early to stay within an expected range. Do NOT inflate severity — a dropped hedge word is minor, not major.

Output ONLY the JSON object. No markdown wrapping.
