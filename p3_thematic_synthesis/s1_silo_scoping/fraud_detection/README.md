# `s1_silo_scoping/fraud_detection/` — Silo working directory (fraud_detection)

Per-silo working folder for the Phase 3 thematic ladder: scoping notes, the
a1/a2/a3/b1/b2 prompt + response files, contradiction scans (l3), and the
c1/c2/c3 cross-silo inputs. Frozen outputs that feed the manuscript are
`b2_analytical_themes.txt` and `b1_descriptive_themes.txt`.

The `experiments/` subfolder holds dated experiment snapshots from the
production runs.
