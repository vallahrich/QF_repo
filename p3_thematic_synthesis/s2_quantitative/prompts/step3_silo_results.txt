## Extract Per Experiment

### Results (array)
For each reported metric:
- **metric_name**: use standardised lowercase_with_underscores names. Use the primary metric names above when applicable.
- **value**: the exact number. If a range, use the midpoint and note the range in unit.
- **uncertainty**: standard deviation, confidence interval, or error bar if reported (e.g., "±0.03", "95% CI [0.78, 0.86]"). Use null if not reported.
- **num_runs**: number of independent runs/seeds averaged, if reported.
- **unit**: unit of measurement (%, seconds, ratio, etc.)
- **higher_is_better**: true/false
- **data_source**: "table", "figure", "text", or "computed"

### Classical Baselines (array)
For each classical method compared against:
- **method_name**: the classical method (e.g., "Gurobi MIP", "Random Forest", "classical Monte Carlo", "CPLEX", "MVO")
- **metric_name**: same metric as quantum result
- **value**: classical result value
- **unit**: unit

### Speedup Claims (array)
- **type**: asymptotic, empirical, theoretical, projected, none
- **factor**: speedup magnitude (e.g., "2x", "quadratic", "O(sqrt(N))")
- **baseline_method**: what classical method is compared
- **conditions**: under what conditions (e.g., "assuming fault-tolerant hardware", "for N > 1000")
- **is_demonstrated**: boolean — was this actually shown or just claimed?
- **caveats**: important caveats or qualifications

### Scalability Data (array)
If the paper tests multiple problem sizes, extract each data point:
- **problem_size**: the scale value (e.g., number of assets, dataset size)
- **num_qubits**: qubits used at this size
- **metric_name**: which metric
- **metric_value**: the result at this size

## Rules
- Extract ALL reported results, not just the primary metrics. If the paper reports execution_time, convergence_rate, or any other metric, include it.
- If the paper has more than 5 quantum experiments, focus on the 5 most distinct/important ones (different algorithms or most comprehensive results). Mention in the output that additional experiments were omitted.
- For table data with many rows, extract: the best quantum result, the worst quantum result, and all classical baseline rows. Do NOT extract every row of a 20-row comparison table.
- If values are only readable from figures (not stated in text/tables), estimate the value and set data_source to "figure".
- Use null rather than guessing — never fabricate values.
- Return ONLY the JSON object.
