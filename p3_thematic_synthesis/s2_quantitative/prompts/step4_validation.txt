### 2. Hoefler Advantage Assessment (per experiment)

For EACH experiment, apply the Hoefler et al. (2023) quantum advantage framework:

- **advantage_status**: 
  - "advantage_demonstrated" â€” quantum outperforms classical on reported metrics AND on meaningful problem size
  - "advantage_claimed_not_demonstrated" â€” authors claim advantage but results don't support it, or only on toy problems
  - "parity_with_classical" â€” roughly equal performance
  - "classical_still_better" â€” classical baseline wins
  - "theoretical_only" â€” no experimental comparison
  - "not_assessed" â€” insufficient data

- **hoefler_viable**: Applying Hoefler et al. (2023) constant-factor analysis:
  - Quadratic speedup (k=2): likely NOT viable â€” error correction overhead (~10^6 operations per logical gate) negates quadratic gains
  - Cubic or higher (k>=3): potentially viable if crossover N* is reachable with available hardware
  - Set true only if speedup_order is cubic+ AND crossover_n is below practical problem sizes
  - Set false for quadratic speedup or if constant factors negate advantage
  - Set null if insufficient complexity data

- **maturity_level**: L0_theory, L1_noiseless_sim, L2_noisy_sim, L3_qpu_small (<=20 qubits), L4_qpu_scale, L5_production

- **crossover_size**, **resources_for_advantage**, **data_loading_bottleneck**, **feasibility_horizon**, **limiting_factors**
