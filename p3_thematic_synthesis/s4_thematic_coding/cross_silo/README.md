# `s4_thematic_coding/cross_silo/` — historical redirect

This directory was scaffolded during the s4 design phase to hold cross-silo
thematic outputs (C1/C2/C3). The actual cross-silo work was relocated to
**[`p3_thematic_synthesis/s5_cross_silo/`](../../s5_cross_silo/)** before the
2026-04-22 production run and is the only authoritative location.

This folder is kept (rather than deleted) to preserve the s4 directory layout
referenced by [`docs/PRODUCTION_ARCHITECTURE.md`](../../docs/PRODUCTION_ARCHITECTURE.md)
and to make the relocation discoverable for any reader following the
historical layout.

**Do not put new artefacts here.** All cross-silo outputs (c1 patterns, c2
grounding aggregate, c3 literature crosswalk) live under `s5_cross_silo/`.
