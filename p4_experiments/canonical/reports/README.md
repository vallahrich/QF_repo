# Canonical Reports Namespace

This is the authoritative home for generated canonical JSON reports such as `phase3_compare.json`, `stats_report.json`, `oracle_tax_table.json`, `sensitivity_grid.json`, `evidence_report.json`, `surviving_engine_failures.json`, and forensic report artifacts.

Per-phase audit JSON outputs live in [audit/](audit/). The canonical root keeps checked state such as `cohort.json`, source documents, compatibility wrappers, pipeline code, outputs, and release artifacts.
