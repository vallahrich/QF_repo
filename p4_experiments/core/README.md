# Phase 4 Core Namespace

This is the authoritative namespace for reusable Phase 4 implementation code.

Use `p4_experiments.core.*` for the circuit registry, QDK bridge, resource-estimation runner, shared circuit templates, schemas, resource profiles, and P4 shortlist inputs. [../common/output/](../common/output/) remains the guarded raw output store for Phase 8 and Phase 8b/8c records.
