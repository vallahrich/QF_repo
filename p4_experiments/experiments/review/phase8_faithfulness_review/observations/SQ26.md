### Concerns raised by Vincent

- instance.json variant tag (QGAN) disagrees with v2 operator_notes which identify exp_1 as the QCBM-Regular default.
- Implemented ansatz_layers=3 is below the paper's default 8 (and below the swept set {4,8,16}); acceptable for resource-estimation tractability but should be noted.
- v2 extraction explicitly flags SQ26-SQ31 as 6 redundant labels for one paper; downstream aggregation should de-duplicate to avoid inflating cohort weight.
- Proxy uses RealAmplitudes, not the paper's qopula RZ/RX/RZZ per-variable structure; this is acceptable under template-proxy methodology but the paper's true gate counts (especially RZZ two-qubit count) will differ from the proxy's resource estimate.

### Recommendations from Vincent

- Update instance.json algorithm_variant_paper to 'QCBM-Regular (default exp_1)' to match v2 operator_notes, or document the QGAN choice if intentional.
- Consider bumping ansatz_layers from 3 to 8 to match the paper's default depth for exp_1, since 6q/8L is small enough to remain tractable.
- Flag the SQ26-SQ31 redundancy at the cohort-aggregation layer so resource estimates are not 6x over-counted for this single paper.
