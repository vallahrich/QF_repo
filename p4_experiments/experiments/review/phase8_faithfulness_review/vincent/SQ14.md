Paper algorithm class is a hardware-efficient PQC/QNN with RY/RZ/CNOT layered HEA blocks (QSTL/QMTL share-and-specify ansatz). RealAmplitudes (RY + linear CNOT entanglement) is a standard proxy for this same variational HEA family.

### ✅ Scale-faithful

Circuit n_qubits=9 matches the canonical v2 num_qubits=9 (P3 winner) exactly; no scale drift.

- `v2_n_qubits`: `9`
- `circuit_n_qubits`: `9`

### ✅ Structurally non-trivial

Bare circuit is a parametrised RealAmplitudes(reps=ansatz_layers) — non-trivial parametrised entangling structure. Full variant adds an ansatz . ansatz^dagger compute-uncompute pair plus measurement, consistent with template-proxy methodology and giving a meaningful gate count for resource estimation.

### ✅ Metadata-consistent

register() declares silo='quantum-ml-finance' and algorithm_family='quantum-ml', matching the cohort entry; instance.json paper_id, experiment_id, n_qubits and silo all align with the v2 extraction.
