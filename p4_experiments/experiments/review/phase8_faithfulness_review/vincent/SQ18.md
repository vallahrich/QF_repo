## Verdict summary

Survey paper with no own algorithm; generic RealAmplitudes ansatz at n=5 is a defensible template proxy within the surveyed VQC family and qubit range, but the circuit/instance carry stale label='SQ11' metadata instead of SQ18.

## Checks

### ✅ Family-faithful

Cohort family 'other-gate-based' matches a survey-of-QML paper; instance.algorithm_variant_paper='qPCA' is one of many algorithms surveyed. A generic VQC-style RealAmplitudes proxy is acceptable for a survey with no single own algorithm.

### ✅ Scale-faithful

Implemented n_qubits=5 sits inside the paper's surveyed finance qubit range 3-20 and matches instance.paper_claimed.num_qubits=5; v2 extraction lists num_qubits as NOT_STATED (survey).

- `v2_n_qubits`: `None`
- `circuit_n_qubits`: `5`

### ✅ Structurally non-trivial

Bare uses ansatz_stretch (RealAmplitudes, linear entanglement, 3 reps); full path applies ansatz . ansatz^dagger compute-uncompute with measurement on 5 qubits. Non-trivial parametrised circuit consistent with NISQ VQC template.

### ❌ Metadata-consistent

circuit.py and instance.json are labelled 'SQ11' (label='SQ11', instance_id='SQ11_v3_proxy_v1', register(label='SQ11', ...), name='SQ11_bare'/'SQ11_full') while the cohort row and v2 extraction key this triple as SQ18. Paper_id and experiment_id agree, so the artefact resolves to the right paper, but the label tag is stale.

## Concerns

- Label drift: artefact files use 'SQ11' identifier instead of 'SQ18'; could cause confusion in downstream aggregation keyed by label_id.
- v2 extraction has all circuit fields = NOT_STATED (survey paper), so faithfulness to a specific algorithm cannot be verified beyond family-level proxy.

## Recommendations

- Rename label/instance_id and register(label=...) in circuit.py from 'SQ11' to 'SQ18' (or document the alias) to keep cohort keying consistent.
- Add a note in instance.notes that this row stands in for the surveyed qPCA/VQC family rather than any specific reference algorithm.
