## Verdict summary

Circuit faithfully implements the paper's QSVM ZZFeatureMap kernel embedding at exact paper scale (3 qubits, reps=2).

## Checks

### ✅ Family-faithful

Paper is QSVM with second-order Pauli-Z (ZZFeatureMap) quantum kernel estimator; circuit uses Qiskit ZZFeatureMap and registers paired U_phi(x)·U_phi(y)^dagger kernel primitive — exact algorithm-family match.

### ✅ Scale-faithful

Paper TSX experiment uses nqb=3, reps=2; circuit uses n_features=3, reps=2.

- `v2_n_qubits`: `3`
- `circuit_n_qubits`: `3`

### ✅ Structurally non-trivial

Bare circuit applies ZZFeatureMap with measurement; full mode appends inverse feature map on a second data point, which is exactly the QSVM kernel-estimation primitive described in the paper (sample U†Φ(xi)UΦ(xj) for kernel entries).

### ✅ Metadata-consistent

algorithm_family='quantum-svm' in instance and registry matches paper; instance.paper_claimed.num_qubits=3 and circuit_depth=reps=2 match v2 extraction.

## Concerns

- Paper specifies 'full' entanglement; instance uses 'linear' entanglement. Minor structural difference but does not change algorithm family or qubit count.
- Instance uses n_samples_train=40 vs paper's 80 (and v2 num_train=80) — only relevant if training-set size is part of cost accounting; not relevant to the per-circuit faithfulness judgment.
- Bare circuit binds parameters from a fixed RNG seed (synthetic features), which is acceptable as the paper's Bloomberg data is not reproducible.

## Recommendations

- Optional: change entanglement='full' in instance.json to exactly match the paper's reported full entanglement on 3 qubits (depth difference is negligible at n=3 but improves provenance fidelity).
