## Verdict summary

Generic RealAmplitudes ansatz_stretch proxy at n=5 is a defensible Tier-1 template stand-in for the SI-PQC/MEDL/WDM algorithm (variational/PQC family), but does not implement the paper's QSVT/LCU block-encoded MaxEnt construction; paper qubit count is NOT_STATED so scale is unverifiable.

## Checks

### ✅ Family-faithful

Paper algorithm SI-PQC is a parameterized quantum circuit trained in a hybrid quantum-classical loop (variational PQC family); cohort tag 'other-gate-based' and a generic RealAmplitudes proxy are an acceptable PQC-family stand-in. Paper's MEDL/WDM rely on QSVT+LCU block-encoding which the proxy does not capture, but proxy is explicitly methodology-sanctioned.

### ✅ Scale-faithful

Paper does not state n_qubits (NOT_STATED in v2 and instance.paper_claimed.num_qubits is null); proxy uses n=5 within the Tier-1 cap (<=12) and is consistent with the small-scale GMM learning example described. Within-factor-2 check is vacuous against unstated n.

- `v2_n_qubits`: `None`
- `circuit_n_qubits`: `5`

### ✅ Structurally non-trivial

Bare circuit is a 5-qubit RealAmplitudes(reps=3, linear entanglement) with bound random parameters; full-accounting variant adds ansatz . ansatz^dagger compute-uncompute and measurement. Non-trivial parameterized + entangling structure consistent with a PQC ansatz proxy.

### ❌ Metadata-consistent

instance.algorithm_variant_paper says 'Quantum-classical hybrid optimization using SI-PQC for GMM learning' and instance_parameters in v2 carry GMM means/variances/weights, but circuit.py ignores those (no GMM target encoded, no training loop, no overlap/fidelity objective). Notes correctly disclose 'does NOT implement the paper's algorithm', so disclosure is consistent but content is a stretched proxy.

## Concerns

- Paper's core machinery (QSVT block-encoding of constraints, LCU combination, exponentiation to amplitude-encode exp(f(x))) is entirely absent from circuit.py.
- GMM target distribution (means [6,14], variances [16,22.5], weights [0.45,0.55]) and 200-epoch training loop from v2 instance_parameters are not exercised by the proxy.
- Paper qubit count is NOT_STATED, so scale-faithfulness cannot be quantitatively verified; n=5 is a Tier-1 author-chosen default rather than a paper-derived figure.
- v2 operator_notes flags SQ21/SQ22/SQ23 as redundant extractions of the same paper, which the cohort retains as separate experiments.

## Recommendations

- Keep the DRIFT_MINOR classification: proxy is methodology-compliant but should not be cited as evidence of MEDL/WDM/QSVT cost.
- If a more faithful proxy is later desired, encode the GMM target amplitude-wise on n=5 qubits and train RealAmplitudes against an overlap objective for a small number of steps (still a proxy, but exercises the hybrid loop).
- Confirm SQ21/SQ22/SQ23 deduplication policy at aggregation time so the same paper does not triple-count toward Phase-8 totals.
