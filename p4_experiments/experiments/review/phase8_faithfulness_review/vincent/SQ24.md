## Verdict summary

B5 implements the paper's qGAN-loaded amplitude estimation pipeline as a faithful template proxy at the paper's exact qubit scale (n=3), with a parametrized variational generator feeding a canonical QAE block (controlled Grover powers + inverse QFT).

## Checks

### ✅ Family-faithful

Paper is a quantum-ml (qGAN) distribution loader with downstream QAE for option pricing; circuit registers algorithm_family=quantum-ml and structurally implements generator + canonical QAE, matching the paper's two-stage pipeline.

### ✅ Scale-faithful

Bare generator uses n=3 work qubits exactly matching paper. Full mode adds num_eval_qubits=3 for QAE (paper used 8 evaluation qubits downstream); 3 vs 8 is within tractable proxy range and well under the cap of 12.

- `v2_n_qubits`: `3`
- `circuit_n_qubits`: `3`

### ✅ Structurally non-trivial

Generator is a parametrized RY-rotation/CX-entangling ansatz (RealAmplitudes); QAE block has eval-register Hadamards, controlled Grover-operator powers (oracle reflection + diffusion via mcx) at powers 2^k, and an inverse QFT — the canonical QAE shape.

### ✅ Metadata-consistent

label=B5, paper_id and silo match cohort; algorithm_family=quantum-ml aligns with cohort/v2 extraction; instance.paper_claimed.num_qubits=3 matches v2 num_qubits=3.

## Concerns

- Generator uses RealAmplitudes (RY rotations + linear CX entanglers) as a template proxy, whereas the paper specifies RY rotations with ring-CZ entanglers; this is an explicitly allowed template-proxy substitution and does not change the gate-count family.
- generator_reps=1 only; paper swept k in {1,2,3} — proxy fixes the lowest depth, which is acceptable for resource-estimation purposes but understates the upper end of the paper's circuit-depth sweep.
- Full-mode num_eval_qubits=3 vs paper's downstream QAE evaluation qubits = 8; tractability-driven and within the methodology's cap, but the QAE oracle tax is correspondingly underestimated relative to the paper's actual demo.

## Recommendations

- Optionally add a comment in circuit.py noting the RealAmplitudes-vs-ring-CZ substitution to make the proxy choice auditable in-line.
- Consider parametrizing generator_reps from instance.json so the depth-sweep (k in {1,2,3}) can be reproduced if needed for sensitivity analysis.
