## Verdict summary

Generic RealAmplitudes ansatz-stretch proxy bears no structural resemblance to the paper's photonic Lloyd-Mohseni-Rebentrost entanglement-based distance-estimation routine, and circuit/instance metadata is tagged 'SQ6' instead of 'SQ25'.

## Checks

### ❌ Family-faithful

Paper is a photonic, non-gate-model LMR distance-estimation experiment (ancilla-projection on entangled (|0>|u>+|1>|v>)/sqrt(2)). Cohort family 'other-gate-based' is a catch-all, but the implemented RealAmplitudes ansatz + inverse is a variational template that does not embody the LMR primitive (no amplitude-encoded data vectors, no ancilla, no projective inner-product measurement). v2 operator_notes explicitly flags PHOTONIC, not gate-model.

### ✅ Scale-faithful

v2 num_qubits=2 (canonical override from P3); circuit n_qubits=4. Ratio 2x is at the boundary; paper-internal max_qubits=4 (8D demo) so 4 is also defensible. Within the factor-of-2 / cap-at-12 tolerance.

- `v2_n_qubits`: `2`
- `circuit_n_qubits`: `4`

### ❌ Structurally non-trivial

Bare circuit is a 4-qubit linear-entanglement RealAmplitudes(reps=3) with random fixed-seed parameters; full variant is ansatz . ansatz^dagger compute-uncompute. No ancilla register, no amplitude encoding of |u>,|v>, no X-basis ancilla projection -- none of the ingredients an LMR distance-estimation circuit would have. It is gate-nontrivial in the abstract sense (multi-layer entangling ansatz) but algorithmically trivial w.r.t. the paper.

### ❌ Metadata-consistent

instance.json sets label='SQ6' and instance_id='SQ6_v3_proxy_v1'; circuit.py @register(label='SQ6', ...) and register_accounting(label='SQ6', ...). Cohort label_id is SQ25. Stale SQ6 tag throughout the implementation. Also paper_claimed.num_qubits=4 vs v2 canonical num_qubits=2 (P3 override winner).

## Concerns

- Implementation does not represent the LMR entanglement-based distance/inner-product subroutine in any recognizable way; it is a pure variational ansatz stretch.
- Paper is photonic / measurement-based; mapping to a Qiskit gate-model proxy intrinsically loses the algorithm's defining structure (ancilla-projection on (|0>|u>+|1>|v>)/sqrt(2)).
- Pervasive label drift: register/accounting/instance all tagged SQ6 while cohort label_id is SQ25.
- instance.parameters.n_qubits=4 conflicts with v2 canonical num_qubits=2 (canonical_metadata.field_changes resolved P3 winner=2).
- instance.notes itself states 'does NOT implement the paper's algorithm' -- proxy faithfulness is acknowledged-absent.

## Recommendations

- If kept as a stretch proxy, rename labels SQ6 -> SQ25 across instance.json, @register, and register_accounting to remove cohort/identifier drift.
- Reconcile n_qubits: either set instance n_qubits=2 to match v2 canonical, or document the choice (max-photon 4-qubit demo) in instance.notes and v2 citations.
- Consider implementing a minimal LMR-faithful proxy: 1 ancilla + 1-3 data qubits, amplitude-encode two reference vectors, Hadamard-controlled state preparation, ancilla projection in X basis, derive inner product from p. Even at small scale this would make the family check honest.
- Add a 'proxy_faithfulness=template_only' flag in instance.notes so downstream resource-estimate aggregation does not over-claim algorithmic fidelity for SQ25.
