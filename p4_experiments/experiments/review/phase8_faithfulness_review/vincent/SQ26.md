## Verdict summary

Generic RealAmplitudes ansatz proxy at paper-scale (6 qubits) is family-faithful for the QCBM/QGAN variational generator; minor drift in ansatz layer count and a stale variant tag in instance.json.

## Checks

### ✅ Family-faithful

Paper algorithm is a variational quantum generative model (QCBM/QGAN with qopula ansatz of RZ/RX/RZZ). Cohort algorithm_family=quantum-ml. A generic RealAmplitudes variational ansatz is an accepted template proxy in the same quantum-ml/variational-NISQ family.

### ✅ Scale-faithful

v2 num_qubits=6 (3 qubits per variable, 2 variables, default exp_1 setup). Circuit n_qubits=6. Exact match, well within factor-of-2 tolerance and below the 12-qubit cap.

- `v2_n_qubits`: `6`
- `circuit_n_qubits`: `6`

### ✅ Structurally non-trivial

build_bare uses ansatz_stretch (RealAmplitudes-style) with linear entanglement and randomized parameters; full variant composes ansatz with its inverse (compute-uncompute) and measures all qubits. This is a structurally non-trivial parameterized circuit suitable as a proxy for a variational generator.

### ❌ Metadata-consistent

instance.json algorithm_variant_paper labels exp_1 as 'QGAN with fully quantum generator and discriminator', but v2 operator_notes specify exp_1 = '6q/8L/2-var QCBM-Regular default'. Also ansatz_layers in instance.json is 3 while v2 reports 8 layers for exp_1 default; both are within the paper's swept range {4,8,16} only loosely (3 is below). Family bucket itself is unaffected.

## Concerns

- instance.json variant tag (QGAN) disagrees with v2 operator_notes which identify exp_1 as the QCBM-Regular default.
- Implemented ansatz_layers=3 is below the paper's default 8 (and below the swept set {4,8,16}); acceptable for resource-estimation tractability but should be noted.
- v2 extraction explicitly flags SQ26-SQ31 as 6 redundant labels for one paper; downstream aggregation should de-duplicate to avoid inflating cohort weight.
- Proxy uses RealAmplitudes, not the paper's qopula RZ/RX/RZZ per-variable structure; this is acceptable under template-proxy methodology but the paper's true gate counts (especially RZZ two-qubit count) will differ from the proxy's resource estimate.

## Recommendations

- Update instance.json algorithm_variant_paper to 'QCBM-Regular (default exp_1)' to match v2 operator_notes, or document the QGAN choice if intentional.
- Consider bumping ansatz_layers from 3 to 8 to match the paper's default depth for exp_1, since 6q/8L is small enough to remain tractable.
- Flag the SQ26-SQ31 redundancy at the cohort-aggregation layer so resource estimates are not 6x over-counted for this single paper.
