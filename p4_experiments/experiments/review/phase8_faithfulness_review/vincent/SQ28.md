## Verdict summary

RealAmplitudes ansatz_stretch proxy at paper-scale 6 qubits is a defensible template proxy for the quantum-ml QCBM/Qopula generator described in the paper.

## Checks

### ✅ Family-faithful

Paper is QCBM/QGAN variational quantum-ml; circuit is a generic variational ansatz (RealAmplitudes) registered under algorithm_family='quantum-ml'. Same family bucket; template-proxy methodology is permitted.

### ✅ Scale-faithful

v2 extraction reports 6 qubits (3 per variable, 2 variables); circuit uses 6 qubits. Exact match, well within factor-of-2 and 12-qubit cap.

- `v2_n_qubits`: `6`
- `circuit_n_qubits`: `6`

### ✅ Structurally non-trivial

Bare uses ansatz_stretch template (parametrised RealAmplitudes with linear entanglement, fixed seed); full variant adds ansatz . ansatz^dagger compute-uncompute pair plus measurement. Non-trivial parametrised entangling structure consistent with a variational generator proxy.

### ✅ Metadata-consistent

Registry tags label='SQ28', paper_id='f94276561f48', silo='quantum-ml-finance', algorithm_family='quantum-ml' all match cohort/instance; instance_id and notes explicitly flag template-proxy authoring. Authoring n_used=6 matches v2 n=6.

## Concerns

- Proxy uses RealAmplitudes (RY + linear CX) rather than the paper's qopula RZ/RX/RZZ gate set; acceptable under template-proxy methodology but not gate-faithful.
- ansatz_layers=3 in instance vs paper's reported depths (4/8/16, default 8); within proxy budget but lighter than paper-scale depth.
- QCBM-specific elements (SPSA training, KL cost, annealing schedule, GA variant) are not modeled; only the forward circuit is exercised, which is expected for resource-estimation proxies.

## Recommendations

- Optional: bump ansatz_layers to 8 to better mirror the paper's default depth for resource estimation, if cost budget allows.
- Optional: note in instance.notes that the proxy gate set diverges from qopula RZ/RX/RZZ for downstream auditors.
