## Verdict summary

RealAmplitudes ansatz at paper-scale 8 qubits is a defensible quantum-ml template proxy for the QCBM/QGAN qopula generator, but uses fewer layers than the paper and a different gate set than the custom qopula ansatz.

## Checks

### ✅ Family-faithful

Paper is QCBM/QGAN variational generative model (quantum-ml family); circuit is a parametrised RealAmplitudes ansatz, same variational/ansatz family bucket.

### ✅ Scale-faithful

Circuit n_qubits=8 matches v2 num_qubits=8 exactly.

- `v2_n_qubits`: `8`
- `circuit_n_qubits`: `8`

### ✅ Structurally non-trivial

Bare circuit is a parametrised RealAmplitudes ansatz (linear entanglement); full variant adds compute-uncompute pair with terminal measurements — non-trivial entangling structure appropriate for an ansatz_stretch proxy.

### ❌ Metadata-consistent

instance.parameters.ansatz_layers=3 diverges from v2 ansatz_layers=16 (and paper options [4,8,16]); paper's qopula ansatz uses RZ/RX/RZZ per-variable rather than RealAmplitudes — acceptable as template_proxy but worth flagging.

## Concerns

- ansatz_layers=3 in instance.json is below the smallest paper option (4) and well below v2 canonical value (16)
- RealAmplitudes (Ry + CX linear) is not the qopula ansatz (RZ/RX/RZZ per-variable) the paper specifies; family bucket preserved but micro-structure differs
- Operator note flags SQ26-SQ31 as redundant — multiple cohort entries map to the same paper

## Recommendations

- Consider raising instance.parameters.ansatz_layers to 8 or 16 to align with v2 and paper depth options for the Phase-8 estimate
- Document in REPRODUCE/notes that this is an ansatz_stretch family proxy, not a qopula-specific implementation
