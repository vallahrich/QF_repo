## Verdict summary

Family- and scale-faithful generic ansatz template proxy (RealAmplitudes, 8 qubits) for a QCBM/qopula generative experiment; ansatz_layers in instance.json (3) drifts from the paper's 8-layer setting recorded in v2.

## Checks

### ✅ Family-faithful

Paper algorithm is a variational quantum generative model (QCBM with qopula ansatz, RZ/RX/RZZ); circuit is a generic variational ansatz (RealAmplitudes) — same quantum-ml / variational-NISQ family bucket. Template-proxy methodology is explicitly allowed.

### ✅ Scale-faithful

Implemented n_qubits=8 matches v2 num_qubits=8 (binning-strategy evaluation, Figure 4 max size for the 2-variable case); within the <=2x and <=12 caps.

- `v2_n_qubits`: `8`
- `circuit_n_qubits`: `8`

### ✅ Structurally non-trivial

Bare uses RealAmplitudes(reps=3) with linear entanglement; full variant composes ansatz with its inverse (compute-uncompute proxy oracle) and measures all qubits. Non-trivial parameterised + entangling structure consistent with a variational generative-model proxy.

### ❌ Metadata-consistent

instance.parameters.ansatz_layers=3 disagrees with v2 instance_parameters.ansatz_reps=8 and paper_claimed.num_qubits/layers context; bare circuit therefore runs at 3 layers instead of the paper's 8. paper_claimed block otherwise matches v2 (num_qubits=8, depth/T-count NOT_STATED -> null).

## Concerns

- instance.json sets ansatz_layers=3 but v2 (and paper) report 8 layers for the QCBM training; bare circuit runs at the lower depth.
- Generic RealAmplitudes (RY + linear CX) does not reproduce the paper's qopula gate set (RZ, RX, RZZ acting per-variable); acceptable as template proxy but worth recording.
- Compute-uncompute 'oracle' is a structural proxy unrelated to the paper's KL/SPSA training loop and Born-machine sampling; acceptable under template-proxy methodology.
- Cohort note flags SQ26-SQ32 as 7 redundant labels from one paper, so SQ32 shares the same proxy with sibling labels.

## Recommendations

- Bump instance.parameters.ansatz_layers from 3 to 8 to match v2 ansatz_reps=8 so the proxy reflects the paper's stated depth at the same qubit scale.
- Optionally annotate the circuit docstring/notes to point at the SQ26-SQ32 redundancy so resource estimates from sibling labels are not double-counted.
