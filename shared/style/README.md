# `shared/style/` — Shared figure styling

Matplotlib styling utilities used by chart-generating scripts across phases (Phase 1 audit dashboards, Phase 4 manuscript figures).

| File | Purpose |
|------|---------|
| `__init__.py` | Package marker. |
| `figure_style.py` | Centralised colour palette, font sizing, and `apply_style()` helper imported by all figure scripts. Source of truth for the visual identity used in the manuscript figures. |
