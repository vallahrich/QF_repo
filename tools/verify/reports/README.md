# `tools/verify/reports/` — Verifier run outputs

JSON outputs from the cross-phase verifier suite (`v1_schema_validate`,
`v2_consistency`, `v3_trace_label`, `v5_recompute_p3`, `v6_check_doc_claims`,
`v7_algorithm_families`, `v9_bridge`), one file per check per date.
`known_drift_*.md` documents accepted drift between checks.
